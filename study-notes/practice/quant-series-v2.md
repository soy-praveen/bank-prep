# Number Series — Practice (Vol. 2)

SBI PO Prelims level (moderate). 40 questions: Q1–Q25 are missing-term (find the value that replaces `?`); Q26–Q40 are wrong-number (one term breaks the pattern — identify it and give its correct value).

Patterns covered: ×2±1, growing difference, squares/cubes ± offset, prime squares, growing-multiplier (×n+k), alternating operations, Fibonacci-like.

## Answer Key, Solutions & Tricks

**Missing-term**

1. **127** — Pattern ×2 + 1 each step (63×2+1). **Trick**: ratios ≈2, and each term = one less than a power of 2 (2^n − 1): 3,7,15,31,63,127 → 2²−1 … 2⁷−1.

2. **129** — Pattern ×2 − 1 (65×2−1). **Trick**: each term = 2^n + 1: 5,9,17,33,65,129 → 2²+1 … 2⁷+1. Compare with Q1 to keep ±1 straight.

3. **34** — Growing difference. **Trick**: difference row 2, 4, 6, 8, **10** (even numbers). 24+10 = 34.

4. **57** — Differences are perfect squares. **Trick**: difference row 1, 4, 9, 16, **25** (1²…5²). 32+25 = 57.

5. **38** — Squares + 2 (n² + 2). **Trick**: subtract 2 → 1, 4, 9, 16, 25, **36**; roots 1,2,3,4,5,**6**. So 36+2 = 38.

6. **217** — Cubes + 1 (n³ + 1). **Trick**: subtract 1 → 1, 8, 27, 64, 125, **216**; cube roots 1…**6**. 216+1 = 217.

7. **169** — Squares of primes. **Trick**: roots are primes 2, 3, 5, 7, 11, **13**; 13² = 169. (Note 1 and non-primes 4,6,8,9,10,12 are skipped.)

8. **720** — Growing multiplier ×2, ×3, ×4, ×5, **×6** (factorials). **Trick**: ratio row 2, 3, 4, 5, **6**. 120×6 = 720.

9. **153** — Growing-multiplier ×2 with rising add: ×2+1, ×2+2, ×2+3, ×2+4, **×2+5**. **Trick**: 74×2 = 148, +5 = 153. Check add row 1,2,3,4,**5**.

10. **16** — Alternating/interleaved. **Trick**: split into two series — positions 1,3,5,7 give 1, 2, 3, **4**; positions 2,4,6,8 give 4, 8, 12, **16** (×4 table). The `?` sits in the 2nd series → 16.

11. **34** — Fibonacci-like (each = sum of previous two). **Trick**: 13+21 = 34. Verify backward: 8+13 = 21, 5+8 = 13.

12. **47** — Fibonacci-like. **Trick**: 18+29 = 47. Backward check: 11+18 = 29, 7+11 = 18.

13. **10** — Simple halving (÷2). **Trick**: ratio row is constant ½ → 320,160,80,40,20,**10**.

14. **126** — Difference grows ×3. **Trick**: difference row 1, 3, 9, 27, **81** (powers of 3). 45+81 = 126.

15. **48** — n² − 1. **Trick**: add 1 → 4, 9, 16, 25, 36, **49**; roots 2,3,4,5,6,**7**. So 49−1 = 48. (Difference row also gives odd numbers 5,7,9,11,**13**.)

16. **38** — Alternating +1, ×2. **Trick**: pattern +1, ×2, +1, ×2, +1, **×2**. Last op is ×2 → 19×2 = 38.

17. **216** — Perfect cubes. **Trick**: cube roots 1, 2, 3, 4, 5, **6**; 6³ = 216.

18. **336** — n³ − n. **Trick**: 2³−2=6, 3³−3=24 … 7³−7 = 343−7 = 336. Equivalent to (n−1)·n·(n+1): 6·7·8 = 336.

19. **487** — ×3 − 2. **Trick**: 163×3 = 489, −2 = 487. Ratio ≈3 each step confirms the multiplier.

20. **243** — ×1.5 each step (×3/2). **Trick**: ratio row constant 1.5 → 162×1.5 = 243. Cross-check: 243 = 3⁵.

21. **37** — n² + 1. **Trick**: subtract 1 → 1, 4, 9, 16, 25, **36**; roots 1…**6**. 36+1 = 37. (Difference row odd: 3,5,7,9,**11**.)

22. **17** — Consecutive prime numbers. **Trick**: after 13 the next prime is 17 (14,15,16 composite).

23. **600** — Growing multiplier ×1, ×2, ×3, ×4, **×5**. **Trick**: ratio row 1, 2, 3, 4, **5**. 120×5 = 600.

24. **45** — Decreasing by squares. **Trick**: difference row −1, −4, −9, −16, **−25** (subtract 1²…5²). 70−25 = 45.

25. **158** — ×2 + 2. **Trick**: 78×2 = 156, +2 = 158. Check: each term = 2×prev + 2.

**Wrong-number** (given → correct)

26. **25 → 26** — Series is n² + 1 (2,5,10,17,**26**,37,50). **Trick**: subtract 1 from each → should be perfect squares 1,4,9,16,**24?**→ 24 isn't a square; 26−1 = 25 = 5². The printed 25 gives 24, breaking the square pattern. Correct term 26.

27. **64 → 63** — Series is ×2 + 1 (…31,**63**,127). **Trick**: each true term = 2^n − 1; 64 = 2⁶ (a power of 2, not one-less). Also 63×2+1 = 127 fits; 64×2+1 = 129 ≠ 127. Correct 63.

28. **124 → 125** — Perfect cubes. **Trick**: cube-root check — 124 has no integer root; the slot is 5³ = 125. Correct 125.

29. **48 → 49** — Prime squares (2²,3²,5²,7²,11²,13²). **Trick**: √48 ≈ 6.9 (not whole); the 7² slot must be 49. Correct 49.

30. **600 → 720** — Growing multiplier ×2,×3,×4,×5,**×6**. **Trick**: ratio row 2,3,4,5,**6**; 120×6 = 720, but 600 = 120×5 uses the wrong multiplier. Correct 720.

31. **58 → 57** — Differences are squares. **Trick**: difference row should be 1,4,9,16,**25**; 32→58 is +26 (not a square). 32+25 = 57. Correct 57.

32. **30 → 29** — Fibonacci-like (each = sum of previous two). **Trick**: 11+18 = 29, not 30. (18+29 = 47 confirms the rest.) Correct 29.

33. **161 → 163** — ×3 − 2. **Trick**: 55×3−2 = 163, not 161. Also 163×3−2 = 487 fits. Correct 163.

34. **338 → 336** — n³ − n (= (n−1)n(n+1)). **Trick**: 6·7·8 = 336; 338 is +2 off. Correct 336.

35. **44 → 45** — Difference grows ×3. **Trick**: difference row 1,3,9,27,**81**; 18→45 needs +27, and 45+81 = 126 fits. Printed 44 gives +26 (breaks ×3). Correct 45.

36. **110 → 108** — ×1.5 each step. **Trick**: ratio row must stay 1.5; 72×1.5 = 108, and 108×1.5 = 162 fits. 110 breaks the constant ratio. Correct 108.

37. **20 → 19** — Alternating +1, ×2. **Trick**: 18+1 = 19 (the "+1" step), then 19×2 = 38. 20 breaks the +1. Correct 19.

38. **34 → 35** — n² − 1. **Trick**: add 1 to each → perfect squares; 34+1 = 35 (not a square) but the 6²−1 slot = 35. Difference row should be odd 5,7,9,11,**13**; 24→34 is +10 (even). Correct 35.

39. **34 → 33** — ×2 − 1. **Trick**: 17×2−1 = 33, and 33×2−1 = 65 fits; 34 breaks it (34×2−1 = 67 ≠ 65). Correct 33.

40. **72 → 74** — Growing-multiplier ×2+1, ×2+2, ×2+3, **×2+4**, ×2+5. **Trick**: 35×2+4 = 74, then 74×2+5 = 153 fits. 72 = 35×2+2 uses the wrong add. Correct 74.
