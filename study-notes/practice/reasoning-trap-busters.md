SBI PO Prelims level. Each of these 40 questions is built around a **specific mistake** that a well-prepared aspirant still makes under time pressure. Solve first, then read the solution — every one names the wrong answer you were tempted by and the trick to never fall for it again.

## Answer Key, Solutions & Tricks

### Syllogisms

**Q1 — (a) Only I follows.**
(a) Method: "Some pens are books" + "No book is a pencil" → the pens that are books cannot be pencils → **Some pens are not pencils** (I, definite). II is not forced.
(b) Common wrong: **(c) Either I or II** — people see two conclusions both dealing with pens/pencils and reflexively pick "either/or."
(c) **Trick:** The only complementary (contradictory) pairs are *Some–No* and *All–Some not*. "Some pens are not pencils" (I) and "Some pens are pencils" (II) are *Some not / Some* — NOT a pair, both can be true together. Since I is definitely established, the answer is simply Only I. Decide by definiteness first; test either/or only when neither is definite.

**Q2 — (c) Either I or II follows.**
(a) Method: Two particular premises, middle term "red" undistributed → nothing definite. I ("Some apples are sweet", type I) and II ("No apple is sweet", type E) form a *Some–No* complementary pair, exhausting all cases → Either I or II.
(b) Common wrong: **(d) Neither** — you correctly see neither is definite and stop there.
(c) **Trick:** When neither conclusion is individually definite, run the complementary-pair test. *Some X are Y* / *No X are Y* covers every possibility → it's Either/Or, never Neither.

**Q3 — (a) Only I follows.**
(a) Method: Water is not stone (from "No stone is water") and water is liquid → **Some liquid is not stone** (I, definite). II "No stone is liquid" is not forced — stone could still be some other liquid.
(b) Common wrong: **(c) Either I or II** — it looks like a stone/liquid pair.
(c) **Trick:** "Some liquid is not stone" (type O) is complementary to "**All** liquid is stone," NOT to "No stone is liquid." They aren't a pair, and I already follows, so it's Only I.

**Q4 — (b) Does not follow.**
(a) Method: All A are B and No B is C → **No A is C** is definitely forced. So "Some A are C" is impossible.
(b) Common wrong: **(a) Follows** — "it's only a *possibility*, so surely it could happen."
(c) **Trick:** Check definiteness FIRST. A possibility conclusion fails the moment its contrary is a *definite* conclusion. Here "No A is C" is locked in, so the possibility is dead.

**Q5 — (a) Only I follows.**
(a) Method: All roses are flowers → by valid conversion, **Some flowers are roses** (I). "All flowers are roses" is not implied.
(b) Common wrong: **(d) Neither** — "the statement is about roses, it says nothing about flowers."
(c) **Trick:** All A are B always yields **Some B are A**. The All→Some conversion is free; never say "nothing about B."

**Q6 — (e) Both follow.**
(a) Method: cups ⊆ plates ⊆ dishes → All cups are dishes (I). That gives Some cups are dishes → convert → **Some dishes are cups** (II).
(b) Common wrong: **(a) Only I** — you get the universal and forget the conversion.
(c) **Trick:** After deriving "All cups are dishes," immediately also claim "Some dishes are cups." Every A→B universal carries a Some-B-are-A with it.

**Q7 — (a) Follows.**
(a) Method: The pens that are inks are blue; the remaining pens are unrestricted and *may* all be blue. No premise blocks it → "All pens are blue" is a valid possibility.
(b) Common wrong: **(b) Does not follow** — "only *some* pens are inks, so 'all' is impossible."
(c) **Trick:** For a possibility conclusion, look for a *blocking definite* conclusion. There is none here (nothing says any pen is non-blue), so the possibility stands.

**Q8 — (b) Only II follows.**
(a) Method: Some locks are doors, and no door is a window → those locks are not windows → **Some locks are not windows** (II, definite). I is not forced.
(b) Common wrong: **(c) Either I or II** — two conclusions about locks/windows tempt the either/or reflex.
(c) **Trick:** "Some locks are windows" (I) and "Some locks are not windows" (II) are *Some / Some-not* — NOT complementary. II is already definite → Only II.

### Inequalities

**Q9 — (d) Neither follows.**
(a) Method: P > Q < R — the inequality direction **breaks** at Q, so there is no definite relation between P and R.
(b) Common wrong: **(c) Either I or II.**
(c) **Trick:** For an inequality Either/Or, the two conclusions must together cover **>, =, and <**. Here I (P>R) and II (P<R) leave out **P = R**, so they aren't complementary → Neither.

**Q10 — (c) Either I or II follows.**
(a) Method: A ≥ B = C → A ≥ C, i.e. A > C **or** A = C, with nothing to decide which.
(b) Common wrong: **(d) Neither.**
(c) **Trick:** A "≥" with no strict info splits *exactly* into ">" or "=" → the textbook Either/Or. (Same logic for ≤ → "<" or "=".)

**Q11 — (e) Both follow.**
(a) Method: X < Y ≤ Z = W. Substitute W = Z: then W ≥ Y (II) and W = Z ≥ Y > X → **W > X** (I).
(b) Common wrong: **(a) Only I** — the "≤" scares people off concluding W ≥ Y.
(c) **Trick:** Replace the equal term (W = Z) and re-read the chain; W inherits everything Z had, including Z ≥ Y.

**Q12 — (a) Only I follows.**
(a) Method: A > B ≥ C = D ≥ E. The single strict ">" (A > B) carries all the way → **A > E** (I). But B ≥ C = D ≥ E is all "≥/=", so only B ≥ E — "B > E" is not guaranteed (they could be equal).
(b) Common wrong: **(e) Both follow** — assuming B > E.
(c) **Trick:** A conclusion of ">" needs at least one strict ">" somewhere on the path between the two terms. From B to E every link is ≥ or =, so you only earn "≥".

**Q13 — (c) Either I or II follows.**
(a) Method: Decode P & Q $ R © S → P > Q = R ≤ S. Between P and S the direction breaks (> then ≤) → no definite relation. Conclusions I (P > S) and II (P ≤ S) cover every case.
(b) Common wrong: **(d) Neither** — "direction breaks, so no relation, so neither."
(c) **Trick:** A direction break only kills a *definite* relation. If the two conclusions are complementary — here P > S and P ≤ S (and "≤" absorbs both "=" and "<") — the answer is Either/Or, not Neither.

**Q14 — (e) Both follow.**
(a) Method: Decode A # B & C # D → A ≥ B > C ≥ D. The strict "B > C" gives **A > D** (I). And A > D automatically means **A ≥ D** (II).
(b) Common wrong: **(a) Only I** — thinking "A ≥ D" is false because the real relation is the stronger A > D.
(c) **Trick:** If A > D is true, the weaker A ≥ D is also true. A strict inequality never invalidates the corresponding non-strict one.

**Q15 — (d) Neither follows.**
(a) Method: L > M < N = O — direction breaks at M → no relation between L and O.
(b) Common wrong: **(c) Either I or II.**
(c) **Trick:** I (L > O) and II (L = O) miss the case **L < O**, so they don't exhaust the possibilities → Neither. (Either/Or would need "L > O" paired with "L ≤ O".)

### Seating & Arrangement

**Q16 — (b) 3.**
(a) Method: N at seat 2, fourth to the right → seat 6. Persons strictly between = seats 3, 4, 5 = 3.
(b) Common wrong: **(c) 4** — counting the gap as equal to "fourth."
(c) **Trick:** "Nth to the right/left" lands N seats away; the number strictly *between* is **N − 1**.

**Q17 — (b) 3.**
(a) Method: Convert both to the same reference. B, 2nd from the right in a row of 8 = 8 − 2 + 1 = 7th from left. A is 3rd from left. Between = 7 − 3 − 1 = 3.
(b) Common wrong: **(c) 4** — doing 7 − 3, or mis-converting B's position.
(c) **Trick:** Bring both ends to one reference (from-left), then "between = big − small − 1."

**Q18 — K is to L's west (left on paper).**
(a) Method: Facing **south**, a person's right hand points **west**. "Third to the right of L" is 3 seats west of L, i.e. 3 seats to the **left** on a west-to-east diagram.
(b) Common wrong: placing K to the **east/right** — treating it like a north-facing row.
(c) **Trick:** Facing south flips left/right: right hand → west, left hand → east. Only for a *north*-facing row does "to the right" mean page-right/east.

**Q19 — Clockwise moves AWAY from G; G is anticlockwise from H.**
(a) Method: Facing the **centre**, the right hand points **anticlockwise**. So G (H's immediate right) is anticlockwise from H. Going clockwise from H therefore moves toward H's *left*, away from G.
(b) Common wrong: "G is clockwise from H."
(c) **Trick:** Facing centre → **right = anticlockwise, left = clockwise**. (Facing *outward* reverses both.)

**Q20 — (a) 3.**
(a) Method: "4th to the left of Q" → 4 seats along Q's left → 3 seats strictly between.
(b) Common wrong: **(b) 4.**
(c) **Trick:** The N−1 rule holds on circles too: Nth position ⇒ N−1 people in between.

**Q21 — (a) 8.**
(a) Method: Total = left-position + right-position − 1 = 5 + 4 − 1 = 8.
(b) Common wrong: **(b) 9** — simply adding 5 + 4.
(c) **Trick:** C is counted once from each end, so subtract the double-count: total = sum of the two positions − 1.

**Q22 — M is seat c4 (i.e., 2 seats anticlockwise from N).**
(a) Method: Facing centre, right = anticlockwise, so "second to the right of N" = 2 steps anticlockwise. On a 6-seat clockwise list N, c1…c5, two steps anticlockwise from N = −2 ≡ position 4 → **c4**.
(b) Common wrong: placing M at **c2** (2 steps clockwise).
(c) **Trick:** Convert "right/left" to clockwise/anticlockwise *before* plotting on a diagram whose numbering runs the other way. Facing centre: right = anticlockwise.

### Directions

**Q23 — North-West.**
(a) Method: B at origin; A = (0, +1) (north), C = (+1, 0) (east). A relative to C = (0−1, +1−0) = (−1, +1) → left and up → **North-West**.
(b) Common wrong: **North** — reading A's direction from B, not from C.
(c) **Trick:** "With respect to C" means re-anchor to C as the origin. A sits above and to the left of C → NW.

**Q24 — 10 m due North.**
(a) Method: Q = (0,0), P = (10,0), R = (10,10), S = (0,10). S relative to Q = (0, 10) → **10 m North**.
(b) Common wrong: **North-West** — assuming the westward leg leaves S left of Q, when it lands exactly above it.
(c) **Trick:** Assign coordinates and compute; don't eyeball. S returns to Q's x-coordinate, so it is due north, not NW.

**Q25 — South.**
(a) Method: North →(90° CW)→ East →(180°)→ West →(90° ACW)→ South.
(b) Common wrong: **North** — cancelling turns loosely instead of stepping through.
(c) **Trick:** Apply one turn at a time. Clockwise: N→E→S→W; anticlockwise is the reverse. From West, 90° anticlockwise → South.

**Q26 — South.**
(a) Method: At sunrise the sun is in the East, so shadows fall **West**. If the shadow (west) is on X's right, then X's right hand points west → X faces **South**.
(b) Common wrong: **North** — putting the shadow in the wrong hand, or **West**.
(c) **Trick:** Sunrise shadow = West; sunset shadow = East. Then "west is on my right" ⇒ facing South (right hand west ⇒ front south).

**Q27 — 0 km (back at the start).**
(a) Method: North 4 vs South 4 cancel; East 3 vs West 3 cancel → net displacement 0.
(b) Common wrong: **14 km** — summing all legs (path length, not displacement).
(c) **Trick:** Direction questions ask for *displacement*. Equal opposite legs cancel; add path lengths only if the question literally says "total distance travelled."

**Q28 — South-East.**
(a) Method: O(0,0) → N 5 → A(0,5). Turn right (now facing East) 5 → B(5,5). Turn right (now facing South) 10 → C(5, −5). C relative to O = (east 5, south 5) → **South-East**.
(b) Common wrong: **North-East** — forgetting the second right turn now points *south*.
(c) **Trick:** Update the facing after every turn (N→E→S→W for successive rights). C lands right-of and below O → SE.

### Blood Relations

**Q29 — The man is the boy's father.**
(a) Method: "The only son of my father" = the speaker himself (he is male and the only son). So the boy is the son of the speaker → the man is his **father**.
(b) Common wrong: **brother** or **uncle** — reading "only son of my father" as a separate person.
(c) **Trick:** "The only son of my father," spoken by a man, is a self-reference — it *is* the speaker.

**Q30 — B is A's maternal uncle.**
(a) Method: B's father's only daughter = A's mother. B is another child of B's father; since there is only ONE daughter, B must be a **son** → B is A's mother's brother → A's maternal uncle.
(b) Common wrong: **aunt** (assuming B is female) or **father**.
(c) **Trick:** "Only daughter" forces B's gender: a second daughter is impossible, so B is male. A's mother is B's sister → B is A's uncle. Don't assume B's gender from the letter.

**Q31 — R is P's grandparent (gender not determinable).**
(a) Method: Q is female (a daughter) and is P's parent; R is Q's parent → R is P's **grandparent**. R's sex is never stated.
(b) Common wrong: **grandfather** — silently assuming male.
(c) **Trick:** Never assign a gender that the puzzle doesn't give. With R's sex unknown, the answer is grandparent, not grandfather.

**Q32 — His sister.**
(a) Method: "The only child of my grandmother" = Rahul's parent (mother or father). That parent's daughter (other than Rahul) = Rahul's **sister**.
(b) Common wrong: **daughter** or **cousin**.
(c) **Trick:** Peel it inside-out: grandmother's only child = Rahul's own parent; her daughter = Rahul's sister.

**Q33 — She is the man's mother.**
(a) Method: "The only daughter of my mother," spoken by a woman, = the speaker herself. So the man's mother is she → she is his **mother**.
(b) Common wrong: **sister** or **aunt**.
(c) **Trick:** Another self-reference: a woman calling out "my mother's only daughter" is naming herself.

**Q34 — Her brother.**
(a) Method: "My father's father" = Sunita's paternal grandfather; his only son = Sunita's father; his son = Sunita's **brother**.
(b) Common wrong: **cousin** or **nephew** — which would arise only if it were the maternal grandfather's son.
(c) **Trick:** "Father's father's only son" pins it to Sunita's own father, so his son is her brother. Trace the chain literally rather than guessing the branch.

### Coding-Decoding

**Q35 — (a) 3.**
(a) Method: 'tall' appears only in the 2nd and 3rd sentences. {5,6,3} ∩ {9,1,3} = 3 → **tall = 3**.
(b) Common wrong: **(b) 5** ('smart', the code shared by sentences 1 and 2) — a deliberate red herring.
(c) **Trick:** Pick the pair of sentences whose *only* common word is the target, then intersect their codes. (Here 'is'=9 and 'smart'=5 are decoys.)

**Q36 — (a) EPH.**
(a) Method: CAT→DBU is +1 on each letter. DOG → E, P, H → **EPH**.
(b) Common wrong: **(b) CNF** — shifting the wrong way (−1).
(c) **Trick:** Derive the rule from the given pair (each letter +1) and apply it in the *same* direction.

**Q37 — (a) 15.**
(a) Method: Rule = sum of positions. F+E+D = 6+5+4 = **15**.
(b) Common wrong: **(b) 654** — concatenating positions instead of summing.
(c) **Trick:** Confirm the rule with the worked example (CAB = 6 = 3+1+2 = sum), then apply the *same* operation.

**Q38 — (a) BBA.**
(a) Method: C (consonant) → previous = B; A (vowel) → next = B; B (consonant) → previous = A → **BBA**.
(b) Common wrong: **(b) DBC** (treating all as +1) or **(c) BZA** (all −1).
(c) **Trick:** Two rules in one — classify each letter as vowel/consonant *first*, then shift it the right way (vowels forward, consonants back).

**Q39 — (a) sa.**
(a) Method: 'clean' appears only in sentences 2 and 3. {ta,na,sa} ∩ {la,sa,da} = sa → **clean = sa**.
(b) Common wrong: **(b) ta** ('fresh') or **(c) la** ('very') — the other repeated codes.
(c) **Trick:** Same isolate-the-target method: intersect only the two sentences sharing the word you want. Ignore codes shared by other pairs.

**Q40 — (a) HAPPY.**
(a) Method: MANGO→NBOHP is +1, so this is a *decode*: reverse it (−1). I→H, B→A, Q→P, Q→P, Z→Y → **HAPPY**.
(b) Common wrong: **(b) JCRRA** — encoding again (+1) instead of decoding.
(c) **Trick:** Note the direction the question asks. Given code→word means reverse the encoding rule (here −1), not re-apply it.
