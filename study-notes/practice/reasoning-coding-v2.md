# Coding-Decoding — Practice (Vol. 2)

SBI PO Prelims level (moderate). 30 questions covering every major type: letter-shift (Caesar), coded-sentence (common-word matching), number/position coding, symbol coding, and conditional coding.

How to read this sheet: attempt the Questions section first, then check the Answer Key for a full worked solution and a reusable **Trick** for each type.

Note: A = 1, B = 2, C = 3, ... Z = 26 throughout. "Opposite" letters (A/Z, B/Y, ...) always add up to 27.

### Type 5 — Conditional coding

For Q25–Q30, use this letter/code key and the four conditions below.

| Letter | E | R | A | N | K | D | P | S | T | M |
|--------|---|---|---|---|---|---|---|---|---|---|
| Code   | 3 | 7 | 1 | 5 | 9 | 4 | 6 | 2 | 8 | 0 |

Vowels here are **A** and **E**; all other letters are consonants. Apply the FIRST condition that fits:

- **(i)** If the first letter is a vowel and the last is a consonant → code BOTH first and last as the code of the first letter.
- **(ii)** If the first letter is a consonant and the last is a vowel → code BOTH first and last as **$**.
- **(iii)** If the first and last letters are BOTH consonants → interchange (swap) their codes.
- **(iv)** If the first and last letters are BOTH vowels → code BOTH as **£**.

Middle letters are always coded normally from the table.

## Answer Key, Solutions & Tricks

### Type 1 — Letter-shift (Caesar)

**Q1. (c) ECPFNG.**
Find the shift from ONE pair of letters: F → H is +2. Confirm with one more: R → T, also +2. The whole word is shifted +2.
CANDLE +2: C→E, A→C, N→P, D→F, L→N, E→G = **ECPFNG**.
**Trick:** Never check all six letters. Read the shift off the first letter (F→H = +2), verify on the second, then apply mechanically.

**Q2. (b) TUVEFOU.**
Shift: T → U = +1.
STUDENT +1: S→T, T→U, U→V, D→E, E→F, N→O, T→U = **TUVEFOU**.
**Trick:** +1 is the most common bank shift — spot it instantly when the coded word "looks one step ahead."

**Q3. (d) EQHCZX.**
Shift: M → L = −1 (going backward).
FRIDAY −1: F→E, R→Q, I→H, D→C, A→Z (A wraps back to Z), Y→X = **EQHCZX**.
**Trick:** For a backward shift, A wraps to Z. Picture the alphabet as a ring so you never get stuck at the ends.

**Q4. (a) VRXQG.**
Shift: L → O = +3.
SOUND +3: S→V, O→R, U→X, N→Q, D→G = **VRXQG**.
**Trick:** Once you know it is +3, count 3 forward on your fingers per letter. Speed comes from committing the shift number first.

**Q5. (e) OCTMGT.**
Shift: P → R = +2.
MARKER +2: M→O, A→C, R→T, K→M, E→G, R→T = **OCTMGT**.
**Trick:** Same +2 as Q1 — the identical repeated letters (R…R → T…T) are a fast self-check: equal letters must give equal codes.

**Q6. (b) XZG.**
This is NOT a fixed shift. D → W: positions 4 and 23, which add to 27. Check O → L: 15 + 12 = 27. G → T: 7 + 20 = 27. Every letter is replaced by its OPPOSITE.
CAT: C(3) → X(24), A(1) → Z(26), T(20) → G(7) = **XZG**.
**Trick:** Opposite letters sum to 27. So opposite of a letter = 27 − its position. If the "shift" seems to change size per letter, suspect opposites and test the 27 rule.

### Type 2 — Coded-sentence (common-word matching)

The method is always the same: two sentences that share exactly ONE English word must share exactly ONE code word — that pins the meaning. Triangulate across three sentences.

**Set A.**
- S1 "mot ka lisen" = bring good books; S2 "pel lisen dora" = good tasty food. Shared English word = "good"; shared code = **lisen** → good.
- S1 & S3 "ka dora nim" = bring food now share "bring"; shared code = **ka** → bring.
- S2 & S3 share "food"; shared code = **dora** → food.
- Leftovers: mot = books, pel = tasty, nim = now.

**Q7. (d) dora** (food).
**Q8. (a) ka** (bring).
**Trick:** Circle the one English word two sentences have in common, then circle the one code word they share — they must match. Repeat for each pair to "triangulate."

**Set B.**
- S1 "sto rej mip" = black tea cup; S2 "rej fan tuk" = tea is hot share "tea" → **rej**.
- S1 & S3 "mip fan gyo" = cup is broken share "cup" → **mip**.
- S2 & S3 share "is" → **fan**.
- Leftovers: sto = black, tuk = hot, gyo = broken.

**Q9. (c) fan** (is).
**Q10. (b) mip** (cup).
**Trick:** Short function words (is, the, of) are usually the code that appears in the MOST sentences. "fan" shows up in two sentences whose only common word is "is."

**Set C.**
- S1 "nok peed zari" = children play games; S2 "zari lom det" = games are fun share "games" → **zari**.
- S1 & S3 "peed det bora" = children enjoy fun share "children" → **peed**.
- S2 & S3 share "fun" → **det**.
- Leftovers: nok = play, lom = are, bora = enjoy.

**Q11. (c) peed** (children).
**Q12. (a) det** (fun).
**Trick:** After fixing two words in a 3-word sentence, the third code word is forced — no guessing needed for the leftovers.

### Type 3 — Number / position coding

**Q13. (b) 40.**
Logic = SUM of letter positions. Check: RED = 18 + 5 + 4 = 27. ✓
BLUE = B(2) + L(12) + U(21) + E(5) = **40**.
**Trick:** If a whole word maps to ONE number, it is almost always the sum of positions. Verify on the given example before trusting it.

**Q14. (a) 6-1-3-5.**
Logic = write each letter's position as a separate number. BAD = 2-1-4. ✓
FACE = F(6)-A(1)-C(3)-E(5) = **6-1-3-5**.
**Trick:** Memorise anchor positions: A=1, E=5, J=10, O=15, T=20, Z=26. Count from the nearest anchor instead of from A.

**Q15. (c) 7-15-4.**
CAT → coded 20-1-3. Note 20-1-3 is T-A-C = CAT REVERSED, then positions. So: reverse the word, then write positions.
DOG reversed = GOD = G(7)-O(15)-D(4) = **7-15-4**.
**Trick:** When the numbers look like the right letters but in the wrong order, test "reverse the word first." Here 20 (=T) tipped us off that the last letter was coded first.

**Q16. (d) 14-12-12-13.**
HAT = 19-26-7. Check: H is 8, but code is 19; 8 + 19 = 27. A is 1, code 26; 1 + 26 = 27. So each code = 27 − position (the OPPOSITE position).
MOON: M(13) → 27−13 = 14, O(15) → 12, O → 12, N(14) → 13 = **14-12-12-13**.
**Trick:** Same "sum-to-27" idea as opposite letters, but with numbers: opposite position = 27 − position. Repeated letters (O, O) must give repeated codes — a built-in check.

**Q17. (c) 37.**
ROSE = 23 = R(18) + E(5): only the FIRST and LAST letters are added (18 + 5 = 23), middle letters ignored.
LILY = L(12) + Y(25) = **37**.
**Trick:** If the sum of ALL letters is too big to match, try first + last only. ROSE's full sum is 18+15+19+5 = 57, not 23 — so it must be first+last.

**Q18. (a) 6-2-4.**
BAD = 4-2-8 = 2×2, 2×1, 2×4 = each position DOUBLED.
CAB = C(3)→6, A(1)→2, B(2)→4 = **6-2-4**.
**Trick:** If codes are consistent multiples of the positions, find the multiplier from one letter (A=1→? gives it instantly). Here A→2 reveals ×2.

### Type 4 — Symbol coding

**Q19. (a) ◆▲■◇◐.**
Straight substitution from the key: R=◆, A=▲, T=■, E=◇, D=◐.
RATED = **◆▲■◇◐**.
**Trick:** Fixed-key symbol coding is pure lookup — go strictly left to right and don't reorder. Distractor (b) swaps two symbols; scanning in order avoids that trap.

**Q20. (a) STEP.**
Reverse the key (symbol → letter): ▼=S, ■=T, ◇=E, ★=P.
▼■◇★ = **STEP**.
**Trick:** To DECODE, first jot the reverse map (symbol→letter) so you never re-scan the table per symbol.

**Q21. (c) ρ**   /   **Q22. (a) ø.**
Same triangulation as coded sentences, just with symbols.
- S1 "π μ ø" = rain brings water; S2 "μ ζ ρ" = brings cold winter share "brings" → μ.
- S2 & S3 "ø ρ φ" = water winter ends share "winter" → **ρ**.
- S1 & S3 share "water" → **ø**.
- Leftovers: π = rain, ζ = cold, φ = ends.
**Trick:** Symbols change nothing about the method — match the one shared word between two lines to the one shared symbol.

**Q23. (a) #^&%.**
Digit→symbol lookup: 3=#, 8=^, 5=&, 2=%.
3852 = **#^&%**.
**Trick:** For digit-symbol codes, encode/decode one digit at a time in order; group the symbols only at the end.

**Q24. (b) 5047.**
Reverse the map: &=5, ~=0, @=4, !=7.
&~@! = **5047**. (Note ~ = 0 is the easy-to-miss one.)
**Trick:** The "0" symbol is the classic distractor. Underline it first so 5047 is not misread as 547.

### Type 5 — Conditional coding

Method for every item: (1) look ONLY at the first and last letters, (2) pick the first matching condition, (3) code the middle letters straight from the table.

**Q25. (a) $ 3 5 8 $.**
R E N T A: first R = consonant, last A = vowel → **condition (ii)** → both ends = **$**. Middle: E=3, N=5, T=8.
= **$ 3 5 8 $**.
**Trick:** Decide the condition from the ends BEFORE coding anything. Consonant-start + vowel-end always means "$ … $".

**Q26. (c) 1 6 8 3 1.**
A P T E R: first A = vowel, last R = consonant → **condition (i)** → both ends = code of first letter = A = 1. Middle: P=6, T=8, E=3.
= **1 6 8 3 1**.
**Trick:** Condition (i) makes the first and last codes IDENTICAL (both = first letter's code). Matching end digits are a quick sanity check.

**Q27. (a) 2 1 5 4 6.**
P A N D S: first P and last S are both consonants → **condition (iii)** → swap their codes: P=6, S=2 become 2 … 6. Middle: A=1, N=5, D=4.
= **2 1 5 4 6**.
**Trick:** "Both consonants → swap the two end codes." Write the normal codes first (6…2), then flip them (2…6).

**Q28. (a) £ 5 4 £.**
E N D A: first E and last A are both vowels → **condition (iv)** → both ends = **£**. Middle: N=5, D=4.
= **£ 5 4 £**.
**Trick:** Two vowels bracket the word → "£ … £". The £ symbol appears ONLY in this both-vowels case, so it is an instant giveaway.

**Q29. (a) 1 9 5 4 1.**
A K N D R: first A = vowel, last R = consonant → **condition (i)** → both ends = A = 1. Middle: K=9, N=5, D=4.
= **1 9 5 4 1**.
**Trick:** Same rule as Q26 — vowel-start + consonant-end → identical end digits equal to the first letter's code.

**Q30. (d) $ 8 1 7 $.**
S T A R E: first S = consonant, last E = vowel → **condition (ii)** → both ends = **$**. Middle: T=8, A=1, R=7.
= **$ 8 1 7 $**.
**Trick:** Consonant-start + vowel-end → "$ … $" (mirror of Q25). Keep a two-line cheat sheet: vowel-start→matching digits/£, consonant-start→$ or swap.

### One-page summary of tricks

1. **Caesar shift:** read the shift from ONE letter, verify on a second, apply. Watch for wrap-around at A/Z.
2. **Opposite letters:** they sum to 27 → opposite = 27 − position. Suspect this when the "shift" size keeps changing.
3. **Coded sentences/symbols:** two lines sharing one English word share one code word — triangulate across three lines; short function words recur most.
4. **Number coding:** one number per word = sum (or first+last) of positions; a list of numbers = each position (possibly reversed, doubled, or 27−position).
5. **Conditional coding:** judge the first + last letters FIRST, apply the first matching rule, then code the middle straight through.
