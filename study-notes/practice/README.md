# Practice Modules — Prelims-Level Question Bank

~200 SBI PO Prelims-level questions, each with a **worked solution + the trick/method**. Built for solo grind after the tutoring window. Do a module, self-check against its answer key, and revisit the tricks you missed.

Difficulty = authentic prelims (moderate). Every answer was solved and verified by hand.

## How to use these + the full mocks

- **Topic drill:** pick a module, time yourself, self-check, note which tricks you missed → revisit that trick in `../reasoning.md` / `../quant.md` / `../english.md`.
- **Full mocks:** the 11 real PYQ papers (2015–2025) live in `src/data/questions/pyq/` — run the app (`npm run dev`) and use the Mocks page for full 100-question timed papers.
- **Priority order:** DI + arithmetic (quant speed) → puzzles → English grammar. That's where your marks move most.
