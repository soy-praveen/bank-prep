## How to grind (suggested plan for 28 July → 1 Aug)

1. **Daily warm-up:** one group from `quant-speed-drill.md` (60 sec) — keeps calc reflexes sharp.
2. **Weak-area drill:** DI + arithmetic modules (your speed bottleneck), timed, self-checked. Build the base table FIRST on every DI.
3. **Trap-busters:** do these twice — they inoculate you against your specific mistakes.
4. **Mixed mini-mocks + PYQ papers:** full timed reps to train topic-switching and skip discipline.
5. After each set: note which **trick** you missed → revisit it in `../reasoning.md` / `../quant.md` / `../english.md`.

**Attempt order on exam day: English → Reasoning → Quant.** Secure the fast stuff, skip any set that isn't cracking in ~1 min. Accuracy > attempts (0.25 negative).
