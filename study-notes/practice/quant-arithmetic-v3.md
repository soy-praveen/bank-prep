## Answer Key, Solutions & Tricks

### Simple & Compound Interest

**1. (b) Rs. 3,000**
SI = (P x R x T) / 100 = (12500 x 8 x 3) / 100 = 300000 / 100 = **3,000**.
Trick: 8% for 3 years = 24% of principal. 24% of 12,500 = 3,000.

**2. (c) Rs. 3,150**
Amount = 15000 x (1.1) x (1.1) = 15000 x 1.21 = 18,150. CI = 18,150 - 15,000 = **3,150**.
Trick: For 2 years, CI% = R + R + (R x R)/100 = 10 + 10 + 1 = 21%. 21% of 15,000 = 3,150.

**3. (c) Rs. 15,000**
For 2 years, difference = P x (R/100)^2 = P x (8/100)^2 = P x 64/10000 = 96.
So P = 96 x 10000 / 64 = **15,000**.
Trick: Difference (2 yrs) = P(R/100)^2; the difference equals the "interest on the first year's interest."

**4. (c) 16 years**
Doubling means interest earned = P. At SI, interest is constant each year, so P is earned in 8 years -> P/8 per year.
To triple, interest needed = 2P -> time = 2P / (P/8) = **16 years**.
Trick: (n-1) rule at SI. Double => interest = 1P in 8 yr. Triple => interest = 2P, so time = 2 x 8 = 16 yr.

**5. (b) Rs. 1,680**
Half-yearly: rate = 10% per half-year, periods = 2. Amount = 8000 x (1.1)^2 = 8000 x 1.21 = 9,680. CI = **1,680**.
Trick: Half-yearly halves the rate (20% -> 10%) and doubles the periods (1 yr -> 2 half-years).

### Profit, Loss & Discount

**6. (b) Rs. 552**
SP = CP x (1 + 15/100) = 480 x 1.15 = **552**.
Trick: 15% of 480 = 72; 480 + 72 = 552.

**7. (c) Rs. 800**
CP = SP / (1 - loss%) = 736 / 0.92 = **800**.
Trick: At 8% loss, SP = 92% of CP. CP = SP x 100/92 = 736 x 100/92 = 800.

**8. (d) 20%**
SP = 1200 x (1 - 0.20) = 1200 x 0.80 = 960. Profit = 960 - 800 = 160. Profit% = 160/800 x 100 = **20%**.

**9. (b) 28%**
Net factor = (1 - 0.10)(1 - 0.20) = 0.9 x 0.8 = 0.72, i.e. 72% of MP is paid, so discount = **28%**.
Trick: Combined discount = a + b - (ab/100) = 10 + 20 - 2 = 28%.

**10. (c) 5% profit**
Let CP = 100. MP = 140. SP = 140 x 0.75 = 105. Profit = 5, so profit% = **5%**.
Trick: Overall factor = 1.40 x 0.75 = 1.05 -> 5% profit.

### Time & Work

**11. (b) 7.2 days**
Take LCM(12, 18) = 36 units. A = 3 units/day, B = 2 units/day, together = 5 units/day. Time = 36/5 = **7.2 days**.
Trick: Combined time = (12 x 18)/(12 + 18) = 216/30 = 7.2 days.

**12. (c) 24 days**
B's one-day work = 1/8 - 1/12 = (3 - 2)/24 = 1/24, so B alone = **24 days**.
Trick: Product-over-difference: (8 x 12)/(12 - 8) = 96/4 = 24.

**13. (b) 12 days**
Men x Days is constant: 15 x 20 = 25 x D -> D = 300/25 = **12 days**.
Trick: More men, fewer days (inverse). 300 man-days / 25 men = 12.

**14. (c) 24 days**
A : B efficiency = 2 : 1. Let B = 1, A = 2 units/day; together 3 units/day. Total work = 3 x 16 = 48 units. A alone = 48/2 = **24 days**.
Trick: If A is twice as efficient and together they take 16 days, A alone takes 16 x 3/2 = 24 days.

**15. (c) 18 hours**
Net fill rate = 1/6 - 1/9 = (3 - 2)/18 = 1/18 per hour, so time = **18 hours**.
Trick: Fill minus empty; net one-part per 18 hours means 18 hours to fill.

### Speed, Time & Distance

**16. (b) 3.5 hours**
Time = Distance / Speed = 210 / 60 = **3.5 hours**.

**17. (b) 9 seconds**
72 km/h = 72 x 5/18 = 20 m/s. To cross a pole, distance = train length = 180 m. Time = 180/20 = **9 seconds**.
Trick: To cross a pole, only the train's own length matters.

**18. (c) 30 seconds**
Total distance = 240 + 360 = 600 m. Time = 600/20 = **30 seconds**.
Trick: To cross a platform, distance = train length + platform length.

**19. (c) 10 seconds**
Opposite directions -> add speeds: 54 + 36 = 90 km/h = 25 m/s. Total length = 120 + 130 = 250 m. Time = 250/25 = **10 seconds**.
Trick: Crossing each other -> relative speed x sum of lengths.

**20. (b) 3 km/h**
Downstream speed = 28/2 = 14 km/h. Upstream speed = 16/2 = 8 km/h. Stream = (14 - 8)/2 = **3 km/h**.
Trick: Stream speed = (downstream - upstream)/2; boat speed = (downstream + upstream)/2.

### Averages

**21. (c) 30**
Sum of 5 numbers = 5 x 27 = 135. Remove 15 -> 120 over 4 numbers -> 120/4 = **30**.

**22. (c) 45 years**
Total of 31 people = 31 x 15 = 465. Total of 30 students = 30 x 14 = 420. Teacher = 465 - 420 = **45**.
Trick: New member's value = new average + (old count x increase) = 15 + 30 x 1 = 45.

**23. (c) 18**
Multiples: 6, 12, 18, 24, 30. Sum = 90. Average = 90/5 = **18**.
Trick: For an evenly spaced set, average = middle term = 18.

**24. (c) 60 kg**
A + B + C = 180. A + B = 110 -> C = 70. B + C = 130 -> A = 50. So B = 180 - 50 - 70 = **60 kg**.

**25. (c) 38**
Wrong sum = 20 x 35 = 700. Correction = 78 - 18 = +60. Correct sum = 760. Correct average = 760/20 = **38**.
Trick: Change in average = correction/count = 60/20 = 3; 35 + 3 = 38.

### Problems on Ages

**26. (c) 30 years**
Let ages be 5x and 7x. (5x + 6)/(7x + 6) = 3/4 -> 20x + 24 = 21x + 18 -> x = 6. A = 5 x 6 = **30**.

**27. (b) 14 years**
Let son = s, father = 60 - s. Six years ago: (60 - s - 6) = 5(s - 6) -> 54 - s = 5s - 30 -> 6s = 84 -> s = **14**. (Check: father 46; 6 yrs ago 40 = 5 x 8.)

**28. (c) 19 years**
Let B ten years ago = b, then A = 3b. Now A = 3b + 10, B = b + 10; difference 2b = 6 -> b = 3. A now = 3(3) + 10 = **19**. (Check: B now 13, difference 6; 10 yrs ago 9 = 3 x 3.)

**29. (c) 17 years**
Ratio 3 : 5; difference 2 parts = 8 -> 1 part = 4. P = 3 x 4 = 12. After 5 years = **17**.

**30. (d) 60 years**
Let son = s, man = 3s. Fifteen years ago: 3s - 15 = 9(s - 15) -> 3s - 15 = 9s - 135 -> 6s = 120 -> s = 20. Man = 3 x 20 = **60**. (Check: 15 yrs ago 45 = 9 x 5.)

### Ratio & Proportion

**31. (c) Rs. 450**
Total parts = 3 + 5 = 8; one part = 720/8 = 90. Larger share = 5 x 90 = **450**.

**32. (b) 15 and 24**
Let numbers be 5x and 8x. (5x + 6)/(8x + 6) = 7/10 -> 50x + 60 = 56x + 42 -> 6x = 18 -> x = 3. Numbers = **15 and 24**.

**33. (b) 8 : 12 : 15**
A : B = 2 : 3 = 8 : 12; B : C = 4 : 5 = 12 : 15. Making B common (12): A : B : C = **8 : 12 : 15**.
Trick: Scale each ratio so the common term (B) matches.

**34. (d) Rs. 50**
Total parts = 2 + 3 + 5 = 10; one part = 100/10 = 10. Largest = 5 x 10 = **50**.

**35. (b) 3 : 2**
40% of A = 60% of B -> 0.4A = 0.6B -> A/B = 0.6/0.4 = 6/4 = **3 : 2**.
Trick: A : B = (second %) : (first %) = 60 : 40 = 3 : 2.

### Percentages

**36. (b) 224**
35% of 640 = 0.35 x 640 = **224**.
Trick: 10% = 64, so 35% = 3.5 x 64 = 224.

**37. (c) 280**
Original x 1.25 = 350 -> original = 350/1.25 = **280**.

**38. (c) 16 2/3%**
Required reduction = increase/(100 + increase) = 20/120 = 1/6 = **16 2/3%**.
Trick: Price up r% -> consumption down [r/(100 + r)] x 100 %.

**39. (c) 500**

**40. (b) 19,800**
20000 x 1.10 x 0.90 = 20000 x 0.99 = **19,800**.
Trick: +10% then -10% always gives a net -1% (= -x^2/100 for x = 10).

### Mixtures & Alligation

**41. (c) 10 litres**
Milk = 3/4 x 40 = 30 L, water = 10 L. Let w litres of water be added: 30/(10 + w) = 3/2 -> 60 = 30 + 3w -> w = **10 litres**. (Milk stays constant.)

**42. (b) 3 : 2**
By alligation: cheaper : dearer = (60 - 48) : (48 - 40) = 12 : 8 = **3 : 2**.

**43. (c) 8 litres**
Water = 10% of 40 = 4 L; alcohol = 36 L (unchanged). For water to be 25%, alcohol is 75% of new total -> new total = 36/0.75 = 48 L. Water added = 48 - 40 = **8 litres**.

**44. (c) 40.5 litres**
Milk left = 50 x (1 - 5/50)^2 = 50 x (0.9)^2 = 50 x 0.81 = **40.5 litres**.
Trick: Replacement formula: initial x (1 - drawn/total)^n.

**45. (c) 12 : 13**
Initial: milk 15 L, water 10 L. Removing 5 L of a 3 : 2 mix removes 3 L milk and 2 L water -> milk 12, water 8. Add 5 L water -> water 13. Ratio = **12 : 13**.

### Partnership

**46. (c) Rs. 2,100**
Ratio of investments = 5000 : 7000 = 5 : 7. B's share = 7/12 x 3600 = **2,100**.

**47. (c) Rs. 1,600**
Capital-months: A = 8000 x 12 = 96,000; B = 12000 x 6 = 72,000. Ratio = 96 : 72 = 4 : 3. A's share = 4/7 x 2800 = **1,600**.
Trick: Share is proportional to (amount x time).

**48. (b) Rs. 1,500**
Ratio = (4 x 12) : (5 x 9) = 48 : 45 = 16 : 15. B's share = 15/31 x 3100 = **1,500**.

**49. (c) Rs. 3,000**
Ratio = 6000 : 8000 : 10000 = 3 : 4 : 5 (total 12). C's share = 5/12 x 7200 = **3,000**.

**50. (a) A: Rs. 2,550, B: Rs. 2,550**
Capital-months: A = 12000 x 12 = 144,000; B = 18000 x 8 = 144,000. Ratio = 1 : 1. Each = 5100/2 = **2,550**.
Trick: Larger capital for fewer months can equal smaller capital for more months — always compare (amount x time).
