## Answer Key, Solutions & Tricks

### Set 1 — Table DI

**1. (c) 2000.**
Fiction total = 240+180+300+150+210 = 1080. Non-Fiction total = 160+120+200+250+190 = 920. Grand total = 1080+920 = **2000**.
**Trick:** Add each *row* to a store total first (A=400, B=300, C=500, D=400, E=400), then sum the store totals: 400+300+500+400+400 = 2000. Round numbers add faster than columns.

**2. (c) 216.**
Fiction total 1080 ÷ 5 stores = **216**.
**Trick:** Average = total ÷ count. Get the column total once and divide — never average each store separately.

**3. (b) 66⅔%.**
Store C: Non-Fiction 200, Fiction 300. 200/300 = 2/3 = **66⅔%**.
**Trick:** "% of" = (part ÷ base) × 100 = A/B. Cancel 200/300 to 2/3 on sight; 2/3 is the standard 66⅔%.

**4. (c) 60%.**
A = 240, D = 150. Difference = 90. 90/150 = 0.6 = **60%**.
**Trick:** "% more than D" uses D as the base: diff/base = 90/150. Cancel to 3/5 = 60%.

**5. (b) 3:4.**
Store B total = 300, Store D total = 400. 300:400 = **3:4**.
**Trick:** Cancel common zeros/factors immediately: 300:400 → 3:4.

### Set 2 — Bar Graph DI

**6. (d) 1080.**
2021: X = 600, Y = 480. Total = **1080**.
**Trick:** Read only the two bars for the asked year; ignore the rest.

**7. (c) 500.**
Model X = 400+500+450+600+550 = 2500. 2500 ÷ 5 = **500**.
**Trick:** Pair values that round nicely: (400+600)=1000, (450+550)=1000, +500 = 2500.

**8. (b) 80%.**
2021: Y = 480, X = 600. 480/600 = 0.8 = **80%**.
**Trick:** "% of X" = Y/X. 480/600 cancels to 4/5 = 80%.

**9. (c) 50%.**
X: 2018 = 400, 2021 = 600. Increase = 200. 200/400 = **50%**.
**Trick:** % increase = rise/original = 200/400 = 1/2 = 50%. Base is always the earlier value.

**10. (c) 150.**
2019 total = 500+400 = 900. 2020 total = 450+300 = 750. Difference = **150**.
**Trick:** Compute each year's total, then subtract — 900 − 750 = 150.

### Set 3 — Pie Chart DI

**11. (b) 10800.**
Rent = 30% of 36000. 10% of 36000 = 3600, so 30% = **10800**.
**Trick:** Find 1% (or 10%) of the total once. 1% of 36000 = 360; scale up as needed.

**12. (c) 3600.**
Food − Education = (25% − 15%) = 10% of 36000 = **3600**.
**Trick:** Subtract the *percentages first* (25−15 = 10), then take one % of the total. Avoids computing both amounts.

**13. (c) 100%.**
Savings 20%, Transport 10%. "% more" = (20−10)/10 = **100%**.
**Trick:** With a common total, compare the shares directly: diff/base = 10/10 = 100%. No need to convert to rupees.

**14. (c) 5:6.**
Food:Rent = 25%:30% = 25:30 = **5:6**.
**Trick:** Ratios can be taken straight from the percentage shares. 25:30 → divide by 5 → 5:6.

**15. (c) 8400.**
Food+Rent+Education = (25+30+15)% = 70% of 36000 = 25200. Average of 3 = 25200 ÷ 3 = **8400**.
**Trick:** Sum the shares (70%), take that % of total, then divide by the count. 70% of 36000 = 25200; ÷3 = 8400.

### Set 4 — Line Graph DI

**16. (c) 150.**
Mall P = 20+30+25+40+35 = **150** (thousand).
**Trick:** Group friendly pairs: (20+30)=50, (25+35)=60, +40 = 150.

**17. (e) May.**
Mall Q values: 25, 20, 35, 30, 40. Highest = 40 in **May**.
**Trick:** For "highest/lowest," just scan the row for the peak value — no arithmetic needed.

**18. (c) 100%.**
P: Apr = 40, Jan = 20. "% more" = (40−20)/20 = **100%**.
**Trick:** Doubling (20 → 40) is always a 100% increase. Spot the double instantly.

**19. (c) 30.**
Mall Q = 25+20+35+30+40 = 150. 150 ÷ 5 = **30** (thousand).
**Trick:** Average = total ÷ count. Q's values are symmetric around 30, which also confirms the mean.

**20. (b) 10.**
March total = 25+35 = 60. April total = 40+30 = 70. Difference = **10** (thousand).
**Trick:** Combine both malls per month, then subtract: 70 − 60 = 10.

### Set 5 — Caselet DI

Base figures: Boys = 60% of 2000 = 1200; Girls = 800.
- Boys: Science 40% = 480, Commerce 25% = 300, Arts 35% = 420. (480+300+420 = 1200 ✓)
- Girls: Science 50% = 400, Commerce 25% = 200, Arts 25% = 200. (400+200+200 = 800 ✓)

**Trick (whole set):** Build the base table first — split boys/girls, then break each into streams — before touching any question. One clean table answers all five parts.

**21. (c) 880.**
Science = boys 480 + girls 400 = **880**.
**Trick:** Add the two Science cells from the base table; don't recompute percentages.

**22. (c) 420.**
Boys Arts = 35% of 1200. (Boys are 100% − 40% − 25% = 35% Arts.) 35% of 1200 = **420**.
**Trick:** Find the leftover share by subtracting the given ones from 100% before multiplying.

**23. (c) 50%.**
Boys Commerce = 300, Girls Commerce = 200. "% more" = (300−200)/200 = **50%**.
**Trick:** % more = diff/base, base = girls' value: 100/200 = 50%.

**24. (b) 21:10.**
Boys Arts = 420, Girls Arts = 200. 420:200 = **21:10**.
**Trick:** Cancel the common factor 20: 420:200 → 21:10.

**25. (c) 25%.**
Total Commerce = 300 + 200 = 500. 500/2000 = **25%**.
**Trick:** 500 out of 2000 → divide by 20 to get per-100 → 25%. (500/2000 = 1/4 = 25%.)
