### Part C — Data Sufficiency (Q31–Q40)

Each question has two statements, I and II. Choose:
- (a) Statement I alone is sufficient, but statement II alone is not
- (b) Statement II alone is sufficient, but statement I alone is not
- (c) Each statement alone is sufficient
- (d) Both statements together are needed (neither alone is sufficient), and together they are sufficient
- (e) Even both statements together are not sufficient

**Q31.** What is the two-digit number?
I. The sum of its digits is 9.
II. The number is 4 times the sum of its digits.

**Q32.** What is the speed of a train?

II. Its length is 180 m.

**Q33.** Is x > y?
I. x = y + 3
II. x^2 > y^2

**Q34.** What is the present age of the father?
I. The father's age is 4 times the son's age.

I. 5 pens cost Rs. 60.

**Q36.** What is the annual rate of simple interest?

**Q37.** Is the integer n even?

**Q38.** What is the two-digit number?

**Q39.** What is the average of five numbers?

**Q40.** What is the two-digit number?
I. It is a prime number between 10 and 20.

## Answer Key, Solutions & Tricks

### Part A — Quadratic Comparison

**Q1. Answer: (d) x <= y**
I. x^2 - 7x + 12 = 0 -> (x-3)(x-4) = 0 -> x = 3, 4
II. y^2 - 9y + 20 = 0 -> (y-4)(y-5) = 0 -> y = 4, 5
Every x-value (3, 4) is <= every y-value (4, 5); the case x = 4 = y occurs, so equality is possible. Hence x <= y.
**Trick:** When the largest root of x equals the smallest root of y and all other x-roots fall below, it is a "<=" not a strict "<". Line the roots up on a number line: x-roots {3,4}, y-roots {4,5} — they touch at 4.

**Q2. Answer: (c) x >= y**
I. x^2 - 11x + 30 = 0 -> (x-5)(x-6) = 0 -> x = 5, 6
II. y^2 - 7y + 10 = 0 -> (y-2)(y-5) = 0 -> y = 2, 5
Smallest x (5) equals largest y (5); all other x-values are larger. So x >= y.
**Trick:** Mirror image of Q1 — smallest x meets largest y means "x >= y". Only the touching point creates the "equal-to" part of the sign.

**Q3. Answer: (b) x < y**
I. x^2 - 6x + 8 = 0 -> (x-2)(x-4) = 0 -> x = 2, 4
II. y^2 - 14y + 48 = 0 -> (y-6)(y-8) = 0 -> y = 6, 8
Largest x (4) < smallest y (6). Complete separation, so strictly x < y.
**Trick:** If the whole x-set sits entirely below the whole y-set (max-x < min-y), it is a strict inequality — no "equal" tail.

**Q4. Answer: (b) x < y**
I. 2x^2 - 9x + 10 = 0 -> discriminant = 81 - 80 = 1 -> x = (9 +/- 1)/4 = 2.5, 2
II. y^2 - 6y + 9 = 0 -> (y-3)^2 = 0 -> y = 3 (repeated)
Largest x (2.5) < y (3). So x < y.
**Trick:** A perfect-square trinomial (b^2 = 4ac) gives one repeated root — treat it as a single value. Here compare {2, 2.5} against 3.

**Q5. Answer: (e) no relation**
I. x^2 - 3x - 10 = 0 -> (x-5)(x+2) = 0 -> x = 5, -2
II. y^2 - y - 6 = 0 -> (y-3)(y+2) = 0 -> y = 3, -2
x = 5 > y = 3, but x = -2 < y = 3. The root ranges overlap, so no consistent relation.
**Trick:** Whenever the two root intervals overlap (here both span from -2 upward), the answer is almost always "no relation". Test just the extreme pairings to confirm a sign flip.

**Q6. Answer: (d) x <= y**
I. x^2 - 13x + 42 = 0 -> (x-6)(x-7) = 0 -> x = 6, 7
II. y^2 - 15y + 56 = 0 -> (y-7)(y-8) = 0 -> y = 7, 8
Max x (7) = min y (7); x = 6 < 7. So x <= y.
**Trick:** For x^2 - Sx + P with consecutive-integer roots, the roots are the two factors of P that add to S. 42 = 6x7, 56 = 7x8.

**Q7. Answer: (c) x >= y**
I. x^2 + 7x + 12 = 0 -> (x+3)(x+4) = 0 -> x = -3, -4
II. y^2 + 9y + 20 = 0 -> (y+4)(y+5) = 0 -> y = -4, -5
Both sets negative. Min x (-4) = max y (-4); x = -3 > -4. So x >= y.
**Trick:** With all-positive middle and last terms, both roots are negative. On the number line -3 and -4 sit to the right of -4 and -5, so x is the larger set.

**Q8. Answer: (a) x > y**
I. x^2 - 15x + 54 = 0 -> (x-6)(x-9) = 0 -> x = 6, 9
II. y^2 - 8y + 15 = 0 -> (y-3)(y-5) = 0 -> y = 3, 5
Min x (6) > max y (5). Complete separation upward, so x > y strictly.
**Trick:** min-x > max-y gives a strict ">". 54 = 6x9 (sum 15), 15 = 3x5 (sum 8) — factor by matching the middle coefficient.

**Q9. Answer: (d) x <= y**
I. x^2 = 49 -> x = +7 or -7
II. y^2 - 14y + 49 = 0 -> (y-7)^2 = 0 -> y = 7
x = 7 equals y; x = -7 < 7. So x <= y.
**Trick:** x^2 = k always yields both signs (+/- sqrt(k)); students who write only +7 will wrongly pick "=". The negative root drags this to "<=".

**Q10. Answer: (c) x >= y**
I. x^2 - 8x + 15 = 0 -> (x-3)(x-5) = 0 -> x = 3, 5
II. y^2 - 4y + 3 = 0 -> (y-1)(y-3) = 0 -> y = 1, 3
Min x (3) = max y (3); x = 5 > 3. So x >= y.
**Trick:** Touching at 3 (max-y = min-x) plus a higher x-root gives ">=".

**Q11. Answer: (e) no relation**
I. 2x^2 - 11x + 12 = 0 -> discriminant = 121 - 96 = 25 -> x = (11 +/- 5)/4 = 4, 1.5
II. y^2 - 6y + 8 = 0 -> (y-2)(y-4) = 0 -> y = 2, 4
x = 4 > y = 2, but x = 1.5 < y = 2. Overlap -> no relation.
**Trick:** For a x^2 + b x + c, quick roots = (-b +/- sqrt(D))/(2a). D = 25 is a perfect square, so roots are clean. Overlapping ranges = no relation.

**Q12. Answer: (b) x < y**
I. x^2 - 22x + 120 = 0 -> (x-10)(x-12) = 0 -> x = 10, 12
II. y^2 - 30y + 224 = 0 -> (y-14)(y-16) = 0 -> y = 14, 16
Max x (12) < min y (14). So x < y.
**Trick:** 224 = 14x16 (sum 30). For larger products, test the factor pair centred near S/2 = 15.

**Q13. Answer: (a) x > y**
I. x^2 - 19x + 90 = 0 -> (x-9)(x-10) = 0 -> x = 9, 10
II. y^2 - 11y + 28 = 0 -> (y-4)(y-7) = 0 -> y = 4, 7
Min x (9) > max y (7). So x > y.
**Trick:** 90 = 9x10 (sum 19), 28 = 4x7 (sum 11). Fully separated sets, x higher — strict ">".

**Q14. Answer: (e) no relation**
I. 5x^2 - 16x + 3 = 0 -> discriminant = 256 - 60 = 196 -> x = (16 +/- 14)/10 = 3, 0.2
II. 2y^2 - 3y - 2 = 0 -> discriminant = 9 + 16 = 25 -> y = (3 +/- 5)/4 = 2, -0.5
x = 3 > y = 2, but x = 0.2 < y = 2. Overlap -> no relation.
**Trick:** sqrt(196) = 14 and sqrt(25) = 5 — memorise perfect squares up to 400 to snap these open. Sign flip across the pairings confirms "no relation".

**Q15. Answer: (b) x < y**
I. x^2 + 12x + 35 = 0 -> (x+5)(x+7) = 0 -> x = -5, -7
II. y^2 + 4y + 3 = 0 -> (y+1)(y+3) = 0 -> y = -1, -3
Max x (-5) < min y (-3). Both negative, but x-set is more negative. So x < y.
**Trick:** With negatives, the number closer to zero is larger. -5 and -7 lie left of -3 and -1, so x is the smaller set.

### Part B — Quantity Comparison

**Q16. Answer: (b) Quantity 1 < Quantity 2**
Q1 = 25% of 320 = 80. Q2 = 40% of 220 = 88. 80 < 88.
**Trick:** Convert percentages to simple fractions: 25% = 1/4 (of 320 = 80), 40% = 2/5 (of 220 = 88). Fraction form avoids decimal slips.

**Q17. Answer: (a) Quantity 1 > Quantity 2**
Q1 = CI = 8000 x (1.1^2 - 1) = 8000 x 0.21 = 1680. Q2 = SI = 8000 x 0.10 x 2 = 1600. 1680 > 1600.
**Trick:** For 2 years, CI - SI = P x r^2 = 8000 x (0.1)^2 = 80, so CI is always the larger by exactly that gap. CI beats SI whenever time > 1 year.

**Q18. Answer: (e) Quantity 1 = Quantity 2**
Q1 = (240 + 360)/30 = 600/30 = 20 m/s. Q2 = 72 x 5/18 = 20 m/s. Equal.
**Trick:** km/h to m/s multiply by 5/18; m/s to km/h multiply by 18/5. Train crossing a platform covers (train + platform) length.

**Q19. Answer: (a) Quantity 1 > Quantity 2**
5x - 8 = 3x + 14 -> 2x = 22 -> x = 11. Q2 = 9. 11 > 9.
**Trick:** Collect variables on one side in one step: (5x - 3x) = (14 + 8) -> 2x = 22.

**Q20. Answer: (e) Quantity 1 = Quantity 2**
LCM(12,18) = 36. HCF(12,18) = 6, x 6 = 36. Equal.
**Trick:** LCM x HCF = product of the two numbers (12 x 18 = 216 = 36 x 6). Handy cross-check.

**Q21. Answer: (b) Quantity 1 < Quantity 2**
Q1 = (14 + 18 + 22 + 26)/4 = 80/4 = 20. Q2 = 21. 20 < 21.
**Trick:** Equally spaced numbers: average = (first + last)/2 = (14 + 26)/2 = 20. No need to add all.

**Q22. Answer: (d) Quantity 1 <= Quantity 2**
x^2 = 49 -> x = +7 or -7. Q2 = 7. When x = 7, equal; when x = -7, less. So Q1 <= Q2.
**Trick:** A squared variable always carries a negative root. Since 7 = 7 (equal) and -7 < 7, the correct sign is "<=", not "<".

**Q23. Answer: (c) Quantity 1 >= Quantity 2**
x^2 - 9x + 20 = 0 -> (x-4)(x-5) = 0 -> x = 4 or 5. Q2 = 4. When x = 4, equal; when x = 5, greater. So Q1 >= Q2.
**Trick:** Both roots are >= the compared value with one touching it — that touch makes it ">=" instead of ">".

**Q24. Answer: (a) Quantity 1 > Quantity 2**
Diagonals = n(n-3)/2. Octagon: 8x5/2 = 20. Heptagon: 7x4/2 = 14. 20 > 14.
**Trick:** Memorise the n(n-3)/2 diagonal formula; more sides always means more diagonals, so an octagon (8) beats a heptagon (7) without full computation.

**Q25. Answer: (b) Quantity 1 < Quantity 2**
Time to double at SI: interest must equal principal, so T = 100/rate = 100/12.5 = 8 years. Q2 = 10. 8 < 10.
**Trick:** Under SI, sum doubles in 100/R years, triples in 200/R years — memorise these shortcuts.

**Q26. Answer: (a) Quantity 1 > Quantity 2**
x/4 + x/6 = 10 -> (3x + 2x)/12 = 10 -> 5x/12 = 10 -> x = 24. Q2 = 20. 24 > 20.
**Trick:** LCM of 4 and 6 is 12; combine to 5x/12 in one move, then x = 10 x 12/5 = 24.

**Q27. Answer: (b) Quantity 1 < Quantity 2**
Together = 1/(1/12 + 1/18). 1/12 + 1/18 = (3 + 2)/36 = 5/36. Time = 36/5 = 7.2 days. Q2 = 8. 7.2 < 8.
**Trick:** Combined time = product/sum = (12x18)/(12+18) = 216/30 = 7.2 days. Faster than adding reciprocals.

**Q28. Answer: (e) relation cannot be established**
x^2 - 5x + 6 = 0 -> (x-2)(x-3) = 0 -> x = 2 or 3. Q2 = 2.5. x = 2 < 2.5 but x = 3 > 2.5. No fixed relation.
**Trick:** When the compared number sits between the two roots, the quantity can be above or below it — answer is "cannot be established".

**Q29. Answer: (a) Quantity 1 > Quantity 2**
Q1 = 3/8 of 640 = 240. Q2 = 5/12 of 540 = 225. 240 > 225.
**Trick:** 640/8 = 80, x3 = 240; 540/12 = 45, x5 = 225. Divide first, then multiply — keeps numbers small.

**Q30. Answer: (c) Quantity 1 >= Quantity 2**
2x^2 = 32 -> x^2 = 16 -> x = +4 or -4. Q2 = -4. When x = 4, greater; when x = -4, equal. So Q1 >= Q2.
**Trick:** Compared against the negative root itself, the quantity equals it in one case and exceeds it in the other — hence ">=".

### Part C — Data Sufficiency

**Q31. Answer: (d) Both statements together are needed**
I alone: digit sum 9 gives 18, 27, 36, 45, ... — many numbers. Not sufficient.
II alone: number = 4 x (digit sum). If number = 10t + u, then 10t + u = 4(t + u) -> 6t = 3u -> u = 2t, giving 12, 24, 36, 48 — many. Not sufficient.
Together: digit sum 9 and u = 2t -> t + 2t = 9 -> t = 3, u = 6 -> 36 (check: 3 + 6 = 9, and 4 x 9 = 36). Unique.
**Trick:** Translate "number = k x digit sum" into 10t + u = k(t + u) and simplify to a digit ratio; then overlay the second clue.

**Q32. Answer: (d) Both statements together are needed**
I alone: time only, no length -> insufficient. II alone: length only, no time -> insufficient.
Together: speed = 180/9 = 20 m/s.
**Trick:** Crossing a pole means distance = train length. Speed needs both distance and time — one statement each supplies exactly one.

**Q33. Answer: (a) Statement I alone is sufficient**
I alone: x = y + 3 means x is always 3 more than y, so x > y. Sufficient.
II alone: x^2 > y^2 could mean x = 5, y = 3 (x > y) or x = -5, y = 3 (x < y). Not sufficient.
**Trick:** A squared inequality hides the sign — never enough to order the originals. A linear "x = y + positive" settles it instantly.

**Q34. Answer: (d) Both statements together are needed**
Let father = f, son = s. I alone: f = 4s — insufficient. II alone: f + 8 = 2(s + 8) -> f = 2s + 8 — insufficient.
Together: 4s = 2s + 8 -> s = 4, f = 16.
**Trick:** Age problems needing a unique value require as many independent equations as unknowns — two unknowns here demand both statements.

**Q35. Answer: (c) Each statement alone is sufficient**
I alone: 60/5 = Rs. 12. II alone: 96/8 = Rs. 12. Each gives the unit price.
**Trick:** A single "quantity costs total" ratio fixes the unit rate — either such statement alone is enough.

**Q36. Answer: (b) Statement II alone is sufficient**
I alone: only the principal, no interest or time -> insufficient.
II alone: rate = (SI x 100)/(P x T) = (640 x 100)/(4000 x 2) = 8%. Sufficient (principal, interest, and time are all inside statement II).
**Trick:** Rate needs SI, principal and time together; statement II already carries all three, while statement I carries only one.

**Q37. Answer: (c) Each statement alone is sufficient**
I alone: n^2 even -> n even. Sufficient. II alone: n + 1 odd -> n even. Sufficient.
**Trick:** Parity facts are self-contained: "square is even" and "successor is odd" each force n even on their own.

**Q38. Answer: (e) Even both together are not sufficient**
Digits sum 8 and differ by 2 -> digits are 5 and 3, giving 53 or 35. Two possibilities, so not unique even together.
**Trick:** Sum-and-difference of digits fixes the digit pair but not their order — a two-digit number can still be either arrangement.

**Q39. Answer: (a) Statement I alone is sufficient**
I alone: average = 250/5 = 50. Sufficient. II alone: largest value alone tells nothing about the mean.
**Trick:** Average depends only on the total and the count; once the sum is given, extra facts (like the largest) are irrelevant.

**Q40. Answer: (d) Both statements together are needed**
I alone: primes 11, 13, 17, 19 — four options. II alone: digit sum 8 gives 17, 26, 35, 44, ... — many.
Together: prime between 10 and 20 with digit sum 8 -> 17 only (1 + 7 = 8).
**Trick:** List the small candidate set from the tighter clue (four primes) and screen with the second clue (digit sum) to land on one.
