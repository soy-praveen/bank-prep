## Answer Key, Solutions & Tricks

### Part A — Error Spotting

**Q1. (C) was present.** RULE — With "neither ... nor", the verb agrees with the nearer subject. The nearer subject "his two assistants" is plural, so it must be "were present."
**Trick:** In neither/nor and either/or, the verb obeys the noun sitting closest to it. Read only the part after "nor."

**Q2. (C) have increased.** RULE — "The number of + plural noun" takes a singular verb; only "A number of" takes a plural verb. So "has increased."
**Trick:** "THE number" = one figure = singular. "A number of" = many = plural.

**Q3. (B) the staff already.** RULE — With "By the time ... arrived" (past), the earlier action needs the past perfect. So "the staff had already submitted."
**Trick:** Two past actions, one earlier — the earlier one takes "had + V3."

**Q4. (C) since the last five years.** RULE — "Since" marks a point of time; a stretch of time takes "for." So "for the last five years."
**Trick:** SINCE a point (since 2019), FOR a period (for five years).

**Q5. (B) in their opinion.** RULE — "Committee" here acts as a single unit, so use the singular pronoun "its." So "in its opinion."
**Trick:** A collective noun acting as one body = singular (its), not "their."

**Q6. (B) who always insists.** RULE — In "one of those officers who ...", the relative pronoun "who" refers to the plural "officers," so the verb is plural: "who always insist."
**Trick:** "One of those X who" — the verb after "who" is plural because it points to X, not to "one."

**Q7. (B) the prizes among.** RULE — "Among" is used for more than two; for exactly two persons use "between." So "the prizes between the two toppers."
**Trick:** BETWEEN for two, AMONG for three or more. The clue word here is "the two."

**Q8. (B) meeting you.** RULE — "Look forward to" ends in a preposition "to," which must be followed by a gerund (-ing), not the base verb. So "look forward to meeting you."
**Trick:** In "look forward to," the "to" is a preposition — always follow it with a verb+ing.

**Q9. (B) than the lights.** RULE — "Hardly ... when" is the correct correlative pair (not "than"). So "Hardly had she entered ... when the lights ..."
**Trick:** Hardly/Scarcely pair with WHEN; No sooner pairs with THAN.

**Q10. (A) There are less.** RULE — "Candidates" are countable, so use "fewer," not "less." So "There are fewer candidates."
**Trick:** FEWER for things you can count, LESS for things you measure (less water, fewer bottles).

**Q11. (B) I think the proposal.** RULE — Redundancy: "In my opinion" and "I think" mean the same thing; using both is repetitive. Drop one.
**Trick:** Watch for double-idea phrases — "In my opinion, I think" says the same thing twice.

**Q12. (B) far more higher.** RULE — Double comparative. "Higher" is already comparative, so "more higher" is wrong. Use "far higher."
**Trick:** Never stack two comparatives: no "more higher," "more better," "most easiest."

**Q13. (B) were asked to submit.** RULE — "Each of the + plural" takes a singular verb. So "was asked to submit."
**Trick:** Each / Every / Either / Neither + noun = always singular verb.

**Q14. (E) No error.** RULE — "Jury" is a collective noun; when members act individually (taking their seats), the plural verb "have" and pronoun "their" are acceptable. The sentence is internally consistent.
**Trick:** Collective noun + members acting separately = plural verb is fine. Consistency is what matters.

**Q15. (B) for winning.** RULE — The correct preposition is "congratulate someone ON something." So "congratulated me on winning."
**Trick:** Congratulate ON, not "for."

**Q16. (C) was unhappy with.** RULE — "Not only ... but also" — the verb agrees with the nearer subject "the shareholders" (plural). So "were unhappy."
**Trick:** Like neither/nor, the "not only ... but also" verb follows the nearest subject.

**Q17. (A) A honest officer.** RULE — "Honest" begins with a silent "h" (vowel sound), so it takes "An." So "An honest officer."
**Trick:** Article choice follows SOUND, not spelling: an honest man, a university, an hour.

**Q18. (A) If I was you.** RULE — In a hypothetical / unreal condition, use the subjunctive "were" for all subjects. So "If I were you."
**Trick:** For imaginary "if" statements, always use "were": If I were you / If he were rich.

**Q19. (B) are so beautiful.** RULE — "Scenery" is an uncountable singular noun, so it takes a singular verb "is." So "The scenery ... is so beautiful."
**Trick:** Scenery, furniture, luggage, information — all uncountable, all singular.

**Q20. (A) She returned back.** RULE — Redundancy: "return" already means "come back," so "returned back" is repetitive. Use "She returned."
**Trick:** Cut the redundant "back" after return, revert, repeat, refer.

### Part B — Sentence Improvement

**Q21. (B) do away with the.** RULE — The phrasal verb is "do away WITH" (to abolish). It always needs "with."
**Trick:** Learn the fixed particle: do away WITH = abolish.

**Q22. (B) when.** RULE — "Scarcely ... when" is the correct correlative (like Hardly ... when). "Than" is wrong here.
**Trick:** Scarcely/Hardly = WHEN. Only "No sooner" takes "than."

**Q23. (A) had studied.** RULE — Third conditional: "If + had + V3, ... would have + V3." Never use "would have" in the if-clause.
**Trick:** No "would" inside the "if" half of a conditional. If-clause takes "had + V3."

**Q24. (A) more efficient than any other.** RULE — When comparing one member with the rest of its own group, add "other." Without it, the sentence illogically compares him to himself.
**Trick:** Comparative + "than any" within the same group needs "any OTHER."

**Q25. (A) senior to me.** RULE — Latin comparatives (senior, junior, superior, inferior, prior, preferable) take "to," not "than."
**Trick:** Senior/junior/superior/inferior always pair with TO.

**Q26. (A) have signed.** RULE — With "neither ... nor," the verb agrees with the nearer subject "the accountants" (plural). So "have signed."
**Trick:** Nor's verb follows the nearest noun — here plural "accountants."

**Q27. (B) than.** RULE — "No sooner ... than" is the fixed pair. "When" is wrong.
**Trick:** No sooner = THAN (not when).

**Q28. (A) that I complete.** RULE — "Insist" is not followed by "on + object + to-infinitive." Use "insist that + subject + base verb" (subjunctive). So "insisted that I complete."
**Trick:** Insist / demand / suggest + THAT + base verb.

**Q29. (A) prefers coffee to tea.** RULE — "Prefer" takes "to," not "than," when comparing two nouns.
**Trick:** Prefer X TO Y.

**Q30. (E) No improvement.** RULE — "Write down their names in capital letters" is already correct: plural "names" for plural students, and "capital letters" is the standard phrase.
**Trick:** Don't over-correct. If subject-verb, number and idiom all fit, keep the original.

**Q31. (A) the organisers called off the match.** RULE — Dangling modifier: "Being a rainy day" wrongly attaches to "the match," which cannot be a rainy day. The main clause needs a logical doer, so "the organisers called off the match" reads best of the options.
**Trick:** An opening participial phrase must describe the subject right after it. Fix a dangler by giving the main clause a real doer.

**Q32. (A) too weak to walk.** RULE — "Too + adjective + to + base verb." So "too weak to walk," not "to walking."
**Trick:** After "too ... to," use the plain (base) verb.

**Q33. (A) is that he was.** RULE — "The reason is because" is redundant (reason + because both give cause). Use "The reason is that."
**Trick:** Never write "reason is because" — replace with "reason is that."

**Q34. (A) one's promises.** RULE — The pronoun must agree with "one"; the correct possessive is "one's."
**Trick:** Start with "one," continue with "one's" — don't switch to "his" or "their."

**Q35. (B) the colder it becomes.** RULE — Parallel comparative structure: "The + comparative ..., the + comparative ..." So "The higher ..., the colder ..." — use the comparative, not the superlative "coldest."
**Trick:** In "The more ..., the more ..." sentences both blanks take the COMPARATIVE form.

### Part C — Word Swap / Usage & Confusables

**Q36. (B) principle / principal.** RULE — "Principal" = head of a college (noun/person); "principle" = a moral rule. They are swapped. Correct: "The principal ... importance of moral principles."
**Trick:** The princiPAL is your PAL (the head person). PrinciplE = rulE.

**Q37. (A) affect / effected.** RULE — "Affect" is the verb (to influence); "effect" as a noun means result. Correct: "little effect on the patient, but the news deeply affected her mood."
**Trick:** RAVEN — Affect = Verb; Effect = Noun. So use "effect" (noun) after "little," and "affected" (verb) as the action on her mood.

**Q38. (B) council / counsel.** RULE — "Counsel" = advice / to advise; "council" = an assembly/body. Correct: "gave his counsel ... the local council met."
**Trick:** CounCIL = a Committee (people). CounSEL = adviSE / a lawyer.

**Q39. (B) complimented / supplemented.** RULE — "Supplement" = to add to (rations); "compliment" = to praise (bravery). Correct: "soldiers were supplemented with rations ... officer complimented them on their bravery."
**Trick:** ComplIment = praIse. Supplement = supply extra.

**Q40. (B) loose / lose.** RULE — "Lose" (verb) = fail to keep / misplace; "loose" (adjective) = not tight. They are swapped. Correct: "careful not to lose his wallet, and the belt felt too loose."
**Trick:** LOOSE rhymes with goose (adjective, extra o = extra slack). LOSE has one o — you "lost" an o. Verb of misplacing = lose.

**Q41. (B) prosecute / execute.** RULE — "Execute" = carry out (a project); "prosecute" = take legal action (a case). Correct: "engineers execute the project ... lawyer will prosecute the fraud case."
**Trick:** exeCUTE = carry out a plan. proseCUTE = pursue in court.

**Q42. (B) adverse / adversely.** RULE — "Adversely" (adverb) must modify the verb "affect"; "adverse" (adjective) must modify the noun "region." They are swapped. Correct: "will adversely affect the crops grown in this adverse low-lying region."
**Trick:** Adverb before a verb: "adversely affect." Adjective before a noun: "adverse effect / adverse region."

**Q43. (A) adopt.** RULE — "Adopt" = to take up / accept formally (a policy). "Adapt" = to adjust; "adept" = skilled.
**Trick:** adOPT = OPT to accept. adAPT = Adjust.

**Q44. (B) affect.** RULE — Here we need a verb meaning "to influence" — "affect." "Effect" as a verb means "to bring about," which is not the sense here.
**Trick:** Verb slot after "may" means Affect (the Verb of the pair).

**Q45. (A) mutual.** RULE — "Mutual" = shared between both parties. "Neutral" = impartial; "moral" = ethical.
**Trick:** MUTUAL = shared by BOTH.

**Q46. (A) admitted.** RULE — "Admit to" = allow to enter/join. "Omit" = leave out; "emit" = give off; "submit" = hand in.
**Trick:** adMITted = let IN.

**Q47. (A) credible.** RULE — "Credible" = believable (the account). "Creditable" = praiseworthy; "credulous" = gullible (a person).
**Trick:** CredIBLE = believABLE. Creditable = deserves credit. Credulous = too trusting.

**Q48. (A) minimise.** RULE — "Minimise" = reduce to the least (losses). The others are unrelated in meaning.
**Trick:** miniMISE = make the MINIMUM.

**Q49. (A) refrain.** RULE — "Refrain from" = hold yourself back from an action. "Restrain" needs an object (restrain someone); the idiom for stopping oneself from doing something is "refrain from."
**Trick:** reFRAIN FROM doing. reSTRAIN someone/something.

**Q50. (A) connect.** RULE — "Connect" = join two things (districts). "Collect," "correct," "collate," "convict" don't fit.
**Trick:** conNECT = join (think of a NETwork linking points).
