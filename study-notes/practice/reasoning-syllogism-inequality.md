# Syllogism & Inequality — Practice

SBI PO Prelims level (moderate). 20 questions: Syllogism (Q1-Q10) and Inequality (Q11-Q20, direct + coded). Attempt in one sitting, then check the key. Every answer is worked and verified below.

## Questions

For each question, mark the option:
**(a)** Only conclusion I follows **(b)** Only conclusion II follows **(c)** Either I or II follows **(d)** Neither I nor II follows **(e)** Both I and II follow

### Syllogism (Q1-Q10)

**Q1.** Statements: All cats are dogs. All dogs are animals.
Conclusions: I. All cats are animals. II. Some animals are cats.

**Q2.** Statements: No pen is a pencil. All pencils are erasers.
Conclusions: I. Some erasers are not pens. II. All erasers being pens is a possibility.

**Q3.** Statements: Some books are pens. All pens are papers.
Conclusions: I. All books are papers. II. Some books are not papers.

**Q4.** Statements: All roses are flowers. Some flowers are red.
Conclusions: I. Some roses are red. II. All red things are flowers.

**Q5.** Statements: All keys are locks. Some locks are doors. All doors are gates.
Conclusions: I. Some keys are gates. II. Some locks are gates.

**Q6.** Statements: Some phones are tablets. No tablet is a laptop.
Conclusions: I. Some phones are not laptops. II. Some tablets are phones.

**Q7.** Statements: All students are boys. Some boys are athletes.
Conclusions: I. Some students are athletes. II. Some students are not athletes.

**Q8.** Statements: All doctors are engineers. All engineers are teachers. No teacher is a nurse.
Conclusions: I. No doctor is a nurse. II. Some teachers are doctors.

**Q9.** Statements: Some fruits are vegetables. All vegetables are green. Some green things are fresh.
Conclusions: I. Some fruits are green. II. Some fruits are fresh.

**Q10.** Statements: All pens are inks. Some inks are blue. No blue is red.
Conclusions: I. Some inks are not red. II. Some pens being blue is a possibility.

### Inequality — Direct (Q11-Q15)

**Q11.** Statement: A > B ≥ C = D > E
Conclusions: I. A > D. II. B > E.

**Q12.** Statement: P ≥ Q = R ≤ S < T
Conclusions: I. P > R. II. P = R.

**Q13.** Statement: L ≤ M < N = O
Conclusions: I. L < O. II. L = N.

**Q14.** Statement: A > B < C ≤ D
Conclusions: I. A > C. II. D > B.

**Q15.** Statements: A ≥ B > C and D > C
Conclusions: I. A > D. II. B < D.

### Inequality — Coded (Q16-Q20)

In the following questions, the symbols are decoded as:
- `P @ Q` means P is not smaller than Q (P ≥ Q)
- `P & Q` means P is not greater than Q (P ≤ Q)
- `P # Q` means P is neither smaller than nor equal to Q (P > Q)
- `P % Q` means P is neither greater than nor equal to Q (P < Q)
- `P $ Q` means P is neither smaller than nor greater than Q (P = Q)

**Q16.** Statements: A @ B, B # C, C & D
Conclusions: I. A # C. II. A % D.

**Q17.** Statements: P % Q, Q $ R, R @ S
Conclusions: I. P % R. II. Q @ S.

**Q18.** Statements: X @ Y, Y $ Z
Conclusions: I. X # Z. II. X $ Z.

**Q19.** Statements: P # Q, Q % R, S @ R
Conclusions: I. P # R. II. S # Q.

**Q20.** Statements: L @ M, M % N, N @ O
Conclusions: I. L # N. II. L # O.

## Answer Key, Solutions & Tricks

### The forced pairs (memorise for syllogism)

| Statement combo | Definite conclusion |
|---|---|
| All + All | All (All A are C) |
| All + No | No (No A is C) |
| No + All | Some C are not A |
| Some + All | Some (Some A are C) |
| Some + No | Some A are not C |
| All + Some / Some + Some | No definite link (often Either/Or or Neither) |

Conversion rule: `All A are B` → `Some B are A`; `Some A are B` → `Some B are A`; `No A is B` → `No B is A`. "All" never converts to "All".

Either/Or test: it applies ONLY when (1) neither conclusion is individually definite, AND (2) the two conclusions are an exact complementary pair — same subject and predicate, one positive and one negative. The recognised complementary pairs are `Some A are B` / `Some A are not B`, `All A are B` / `Some A are not B`, and `No A is B` / `Some A are B`. If the two conclusions are not a complementary pair, the answer is Neither, not Either/Or.

---

**Q1 — (e) Both.** All+All gives `All cats are animals` (I follows). Convert it: `Some animals are cats` (II follows).
**Trick:** All+All → All; then any "All A are C" converts to "Some C are A", so a matching Some-conclusion rides along for free — often "Both".

**Q2 — (a) Only I.** `No pen is pencil` = `No pencil is pen`. Pencils are erasers and are not pens, so `Some erasers are not pens` (I follows — this is the No+All → "Some C are not A" pattern). Since some erasers are definitely not pens, `All erasers are pens` is impossible, so possibility II fails.
**Trick:** No+All → "Some (last term) are not (first term)". A "possibility" conclusion dies the moment a definite "some are not" already contradicts it.

**Q3 — (c) Either I or II.** Some+All gives only `Some books are papers` (definite). `All books are papers` (I) and `Some books are not papers` (II) are each possible but not definite, and they form the complementary pair All/Some-not with the same subject-predicate. So Either/Or.
**Trick:** All + Some (or Some + something that leaves the rest of the subject unknown) → watch for the All/Some-not complementary pair. Both undefined + exact opposites = Either/Or.

**Q4 — (d) Neither.** Middle term "flowers" is undistributed (`some flowers are red` says nothing about which flowers). `Some roses are red` — not definite. `All red are flowers` — `some flowers are red` only converts to `some red are flowers`, never "all". The two conclusions are NOT a complementary pair (different subject/predicate), so it is Neither, not Either/Or.
**Trick:** "Some X are Y" never upgrades to "All Y are X". Different subject/predicate in the two conclusions rules out Either/Or.

**Q5 — (b) Only II.** `Some locks are doors` + `All doors are gates` → `Some locks are gates` (II follows). For I, `All keys are locks` + `Some locks are doors`: the locks that are doors need not be keys, so no link keys→gates.
**Trick:** Some+All chains forward (`Some B are C`, `All C are D` → `Some B are D`), but "All A are B" + "Some B are..." does NOT push down to A.

**Q6 — (e) Both.** `Some phones are tablets` + `No tablet is laptop`: the phone-tablets are not laptops → `Some phones are not laptops` (I, the Some+No pattern). Convert `Some phones are tablets` → `Some tablets are phones` (II).
**Trick:** Some+No → "Some (first term) are not (last term)". Every "Some A are B" gives you "Some B are A" for free.

**Q7 — (c) Either I or II.** `All students are boys` + `Some boys are athletes`: the athletic boys need not be students. `Some students are athletes` (I) — not definite. `Some students are not athletes` (II) — not definite. Same subject-predicate, one positive one negative → complementary pair → Either/Or.
**Trick:** The classic Either/Or trap: All A are B + Some B are C leaves "Some A are C" / "Some A are not C" both open — that pair is complementary, so Either/Or (never Neither here).

**Q8 — (e) Both.** All+All: `All doctors are teachers`. Then `No teacher is nurse` → `No doctor is nurse` (I). And `All doctors are teachers` converts to `Some teachers are doctors` (II).
**Trick:** Build the longest All-chain first (doctors→engineers→teachers), then apply the "No" at the end; the converted "Some" rides along.

**Q9 — (a) Only I.** `Some fruits are vegetables` + `All vegetables are green` → `Some fruits are green` (I). For II, `Some green are fresh` — the green fruits need not be the fresh green ones, so `Some fruits are fresh` is not definite. I is definite, so this is not an Either/Or (and the conclusions are not a complementary pair anyway).
**Trick:** A "some" statement further down the chain (some green are fresh) cannot be pulled back onto a specific subset (the green fruits).

**Q10 — (e) Both.** `Some inks are blue` + `No blue is red` → the blue inks are not red → `Some inks are not red` (I). II is a possibility: pens are a subset of inks and some inks are blue, so nothing forbids some pens from being blue → possibility holds.
**Trick:** A possibility conclusion follows unless something makes it impossible. Here no rule blocks pens∩blue, so "possible" is true.

---

**Q11 — (e) Both.** A > B ≥ C = D > E. Chain A > B ≥ C = D is all "greater/equal-or-greater" with at least one strict `>`, so **A > D** (I). Chain B ≥ C = D > E has a strict `>` at the end, so **B > E** (II).
**Trick:** Unbroken same-direction chain: as long as every link points the same way (≥, =, >) and at least one link is strict `>`, the endpoints get a strict `>`. All links `=`/`≥` with no strict → only `≥`.

**Q12 — (c) Either I or II.** P ≥ Q = R gives **P ≥ R**, i.e. P > R OR P = R. Neither alone is definite; together they are the complementary pair (> and =). Either/Or. (The S, T part is a distractor — no P–S/T link.)
**Trick:** A derived `≥` between the two conclusion variables splits exactly into "> " and "=". If the two conclusions are precisely those two, it is Either/Or.

**Q13 — (a) Only I.** L ≤ M < N = O → L ≤ M < N gives L < N, and N = O, so **L < O** (I). L = N is false since L < N. Not a complementary pair, so not Either/Or.
**Trick:** `≤` then `<` still yields a strict `<` across (the strict link dominates).

**Q14 — (b) Only II.** A > B < C ≤ D. A and C both sit above B but there is no direct A–C link → I not definite. D ≥ C > B → **D > B** (II).
**Trick:** A change of direction (`>` then `<`) breaks the chain — the two ends around the "valley" (or "peak") have no forced relation.

**Q15 — (d) Neither.** A ≥ B > C and D > C. Both A and D are above C, but two things bigger than a common item have no forced order → I (A > D) not definite; II (B < D) not definite. Conclusions are about different variable pairs → not a complementary pair → Neither.
**Trick:** "Both greater than C" tells you nothing about how the two big items compare. No common directional chain between them = Neither (only genuine complementary pairs give Either/Or).

---

**Q16 — (a) Only I.** Decode: A ≥ B, B > C, C ≤ D. A ≥ B > C → **A > C** = `A # C` (I). For II, A > C ≤ D has a direction change, so no A–D link → `A % D` (A < D) not definite.
**Trick:** Decode first, then apply the chain rule. `≥` then `>` → strict `>`; a following `≤` breaks it.

**Q17 — (e) Both.** Decode: P < Q, Q = R, R ≥ S. P < Q = R → **P < R** = `P % R` (I). Q = R ≥ S → **Q ≥ S** = `Q @ S` (II).
**Trick:** `@` = ≥, `&` = ≤, `#` = strict >, `%` = strict <, `$` = =. Reading the sentence form ("neither smaller nor equal" = strictly greater) is the whole game.

**Q18 — (c) Either I or II.** Decode: X ≥ Y, Y = Z → **X ≥ Z**. That is X > Z (`X # Z`, I) OR X = Z (`X $ Z`, II) — the exact complementary pair. Either/Or.
**Trick:** Same as direct: a derived `≥` between the two conclusion variables, asked as ">" and "=", is textbook Either/Or.

**Q19 — (b) Only II.** Decode: P > Q, Q < R, S ≥ R. P > Q < R is a direction change → I (`P # R`, P > R) not definite. S ≥ R > Q → **S > Q** = `S # Q` (II).
**Trick:** Watch the "valley" at Q (P > Q < R) — it kills the P–R conclusion; meanwhile S ≥ R > Q chains cleanly to strict >.

**Q20 — (d) Neither.** Decode: L ≥ M, M < N, N ≥ O. L ≥ M < N breaks (direction change), so I (`L # N`) fails. For II, L and O connect only through the broken middle → no L–O link, `L # O` fails. Different variable pairs → not complementary → Neither.
**Trick:** When the middle link reverses direction, neither end-to-end conclusion survives; if the two conclusions also target different pairs, it is a clean Neither.
