# Mixed Mini-Mock 3

Timed: 22 min. Negative marking 0.25.

SBI PO Prelims level. 30 questions in real-paper proportion — 12 English, 9 Quant, 9 Reasoning — with topics jumbled exactly like a live paper (one DI set and one puzzle set embedded). All content is fresh.

## Strategy

- Budget roughly 20 min solving + 2 min buffer. That is about 40 sec per question on average — but never spend more than 60 sec on any single one.
- Two-pass approach: Pass 1 grabs the sure marks (error-spotting, synonyms, simplification, direction, ranking). Pass 2 handles the DI set, the puzzle set, and anything you flagged.
- Do the DI set (Q7-Q8) and puzzle set (Q13-Q14) as blocks — the setup cost is shared across both questions, so never solve just one and move on.
- Negative marking is 0.25. Skip blind guesses. Attempt only when you can eliminate at least 2 options — that shifts the odds in your favour.
- English is your fastest section here (12 marks). Bank them first to build a cushion, then invest the saved time in the two sets.

## Answer Key, Solutions & Tricks

**1. (c) 64.** 15% of 240 = 36; 25% of 160 = 40; 36 + 40 - 12 = 64.
**Trick:** 25% of a number = quarter of it (160/4 = 40); 15% = 10% + 5% (24 + 12 = 36). No long multiplication needed.
Skip-if-stuck: Never — this is a free 30-sec mark.

**2. (c).** "The number of students ... has increased." *The number of* takes a singular verb, so "have increased" is wrong.
**Trick:** "The number of" = singular (a single count). "A number of" = plural (many). Memorise this pair — banks test it every session.
Skip-if-stuck: Rarely; if unsure, "have" after a singular head noun is the usual trap.

**3. (c) Both I and II.** P > Q >= R = S gives P > S (all strict/equal links preserve >). R = S < T gives T > R. Both hold.
**Trick:** A conclusion is true only if every link in the chain agrees in direction. Here no link opposes, so both flow through.
Skip-if-stuck: If a chain has a reversal or an "either/or" (=/<) gap, pause; this one is clean.

**4. (b) 10% decrease.** Net factor = 1.20 x 0.75 = 0.90, i.e. a 10% fall.
**Trick:** For successive % changes a and b, net = a + b + (ab/100) = 20 - 25 + (20 x -25/100) = -5 - 5 = -10%.
Skip-if-stuck: Never; the +/- formula is 15 seconds.

**5. (a) compelling.** "Compelling evidence" is the fixed collocation (evidence so strong it forces a conclusion).
**Trick:** Test collocation, not just meaning. "Compulsive" = habitual (a compulsive liar); "compulsory" = mandatory. Only "compelling" pairs with evidence.
Skip-if-stuck: Eliminate compulsive/compulsory (wrong sense) and pick from the rest.

**6. (a) GMPXFS.** GARDEN -> HBSEFO is each letter +1. FLOWER +1 = G, M, P, X, F, S.
**Trick:** Decode the pattern on ONE given letter pair first (G->H = +1), then apply blindly. F+1=G, L+1=M, O+1=P, W+1=X, E+1=F, R+1=S.
Skip-if-stuck: If the shift is irregular, move on; a uniform +1 like this is a guaranteed mark.

**7. (c) 510.** 2024 column: 150 + 200 + 160 = 510.
**Trick:** Add the column top-to-bottom in one sweep; don't re-read rows.
Skip-if-stuck: Do this before Q8 — you'll reuse the same table read.

**8. (b) 25%.** P: 120 -> 150, rise of 30. 30/120 = 1/4 = 25%.
**Trick:** Increase as a fraction of the ORIGINAL (120), not the new value. 30/120 simplifies straight to 1/4.
Skip-if-stuck: Never divide by the new figure — that is the classic DI trap.

**9. (c) relentless.** "Relentless efforts" = unremitting, tireless — the intended praise.
**Trick:** Positive context ("praised") needs a positive/strong word. Reluctant and reticent are negative/passive; eliminate them instantly.
Skip-if-stuck: Cross out the clearly negative options and pick the vigorous one.

**10. (a) 3 km East.** North 5, then right = East 3, then right = South 5. The two 5s (North then South) cancel; net is 3 km East.
**Trick:** Sketch it. Opposite equal legs cancel; only the lone leg (East 3) survives.
Skip-if-stuck: Draw the path — never track direction in your head on turns.

**11. (b) 30 years.** Let ages be 5x and 7x. (5x+6)/(7x+6) = 3/4 -> 20x+24 = 21x+18 -> x = 6. A = 5x = 30.
**Trick:** Cross-multiply once and the x-terms nearly cancel (20x vs 21x). Present age = 5 x 6.
Skip-if-stuck: Slightly slower; flag it for Pass 2 if the algebra stalls.

**12. (b) B.** Order is B (topic: EVs were impractical) -> C (however, batteries improved) -> A (this led to adoption) -> D (today they dominate). B introduces the subject with no back-reference, so it opens.
**Trick:** The opening sentence has no pronoun/connector pointing backward ("this", "however", "they"). Only B is self-standing.
Skip-if-stuck: To find the opener, just eliminate every sentence starting with a linker.

**13. (a) P.** Fill: T=1 (lowest), Q=4, S above Q so S=5. P immediately above R leaves floors 2 and 3 -> R=2, P=3. Floor 3 = P.
**Trick:** Place the absolute clues first (T lowest, Q on 4), then the "above" clues squeeze the rest.
Skip-if-stuck: Solve the whole arrangement once for both Q13 and Q14; don't restart.

**14. (b) 2.** Final order: 1=T, 2=R, 3=P, 4=Q, 5=S. Between S(5) and R(2) sit floors 3 and 4 = 2 people (P and Q).
**Trick:** "Between" = subtract floor numbers minus 1: (5 - 2) - 1 = 2.
Skip-if-stuck: Reuse the Q13 chart — zero extra setup.

**15. (a) best singers.** After "one of the best" the noun must be plural: "one of the best singers."
**Trick:** "One of the [superlative] + plural noun" is a fixed frame. Singular "singer" is always wrong here.
Skip-if-stuck: Never; this pattern is memorisable.

**16. (a) 25.** Sum of 5 = 27 x 5 = 135. Remove 35 -> 100. New average = 100/4 = 25.
**Trick:** Recover the total from average x count, subtract, divide by the new count. Don't overthink.
Skip-if-stuck: Never; pure two-step arithmetic.

**17. (c) frank.** Candid = open, honest, frank.
**Trick:** Link candid to "candidly speaking" = speaking openly. Frank is the synonym.
Skip-if-stuck: If unknown, recall the phrase "candid camera" (unposed, honest shots).

**18. (b) Sister.** Grandfather's only son = the man's father. The father's daughter = the man's sister.
**Trick:** Resolve inside-out: innermost relation first ("grandfather's only son" = father), then apply the outer one.
Skip-if-stuck: Write the chain left-to-right; don't hold it mentally.

**19. (a) 7.2 days.** Combined rate = 1/12 + 1/18. LCM(12,18)=36; A=3 units/day, B=2 units/day -> 5 units/day. Time = 36/5 = 7.2 days.
**Trick:** Use LCM as total work (36 units) so rates become whole numbers (3 and 2). Time = total/combined rate.
Skip-if-stuck: If fractions feel slow, the LCM-units method removes all fraction addition.

**20. (a) To face a difficult situation bravely.** "Bite the bullet" = endure something painful/unavoidable with courage.
**Trick:** Origin image — soldiers biting a bullet during surgery without anaesthetic: enduring pain bravely.
Skip-if-stuck: If the idiom is unknown, don't guess under negative marking — skip.

**21. (b) 64.** Pattern is n -> n squared. 8 squared = 64.
**Trick:** 5->25, 6->36, 7->49 are perfect squares; extend the sequence. 8 squared = 64.
Skip-if-stuck: Never; spot "square" from 25, 36, 49 instantly.

**22. (a) Rs. 800.** SI = P x R x T / 100 = 8000 x 5 x 2 / 100 = 800.
**Trick:** 5% of 8000 = 400 per year; over 2 years = 800. No formula sheet needed.
Skip-if-stuck: Never; simple interest is one line.

**23. (c) scarce.** Abundant = plentiful; its opposite is scarce (in short supply).
**Trick:** Plenty, ample, large, full are all synonyms of abundant — one odd word out is the antonym.
Skip-if-stuck: Eliminate every option that MEANS abundant; the survivor is the answer.

**24. (b) Only II follows.** All pens are books -> conversion gives "some books are pens" (II true). Pens and pencils share no direct link (the pencils connect only to books), so I does not follow.
**Trick:** "All A are B" always yields "Some B are A." For I you'd need pens tied to pencils, but no such bridge exists.
Skip-if-stuck: Draw two circles: pens inside books; pencils merely overlap books. Pens-pencils overlap is not guaranteed.

**25. (a) Rs. 2,100.** Investment ratio 5000:7000 = 5:7 (12 parts). B's share = 7/12 x 3600 = 2100.
**Trick:** Same time period, so profit splits by investment ratio directly. 3600/12 = 300 per part; B gets 7 x 300.
Skip-if-stuck: Reduce the ratio first (5:7), then one part = total/12.

**26. (a) introduced ... curb.** Past-tense main verb "introduced"; "to + base form curb" after the purpose infinitive.
**Trick:** "to ______" always takes the base verb (curb), never curbing/curbed. That alone kills b, c, e; subject-verb agreement kills d.
Skip-if-stuck: Lock the second blank first ("to curb") — it eliminates four options at once.

**27. (a) 19th.** Position from right = total - position from left + 1 = 25 - 7 + 1 = 19.
**Trick:** The "+1" is essential (both ends count the person once). 25 - 7 = 18, then +1 = 19.
Skip-if-stuck: Never; memorise Left + Right = Total + 1.

**28. (a) than.** The correlative is "No sooner ... than," not "no sooner ... when."
**Trick:** Pair up correlatives: "no sooner-than", "hardly-when", "scarcely-when". Match the opener to its fixed partner.
Skip-if-stuck: If the opener is "no sooner," the answer is always "than."

**29. (b).** "Each of the boys ... was given." *Each* is singular, so "were given" must be "was given."
**Trick:** Each / every / one of / neither = singular verb, regardless of the plural noun that follows ("boys").
Skip-if-stuck: Whenever a sentence starts with "Each of," check the verb for singular agreement first.

**30. (b) illiterate.** A person unable to read or write = illiterate.
**Trick:** Prefix "il-" (not) + literate (able to read) = illiterate. Ignorant means lacking knowledge, not literacy.
Skip-if-stuck: Don't confuse with "ignorant" (no knowledge) — the clue is specifically read/write.
