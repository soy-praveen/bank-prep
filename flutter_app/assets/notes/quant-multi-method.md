# Quant Multi-Method (pick the fastest) — Practice

SBI PO Prelims level. Each problem below is solved by 2-3 **different** methods,
ranked **fastest-first**. The goal is not just the answer — it is training your
eye to spot the quickest route the moment you read the question. Every answer
has been worked out and cross-checked.

A quick note on the mindset: in Prelims you have roughly 30-40 seconds per
question. The "fastest" method is usually the one that avoids writing anything
down. Slower methods are still worth knowing — they are your safety net when
the fast trick does not obviously apply, or when you want to confirm.

## Problems

---

### Problem 1 — Find 45% of 680

**Answer: 306**

**Method 1 (fastest) — Building blocks (10% + 5% chunks)**
- 10% of 680 = 68, so 40% = 68 x 4 = 272
- 5% is half of 10% = 34
- 45% = 272 + 34 = **306**
- ~8 seconds, fully mental.

**Method 2 — Fraction table**
- 45% = 9/20. Divide first: 680 / 20 = 34.
- 34 x 9 = 306. **306**
- ~12 seconds. Clean when the % is a "nice" fraction.

**Method 3 — Direct multiplier**
- 680 x 0.45 = 306. **306**
- ~15 seconds if you multiply on paper.

**Use when...** the percentage breaks into round chunks (5, 10, 25, 50) — go
building-blocks. If it maps to a clean fraction (like 45% = 9/20), the fraction
route is tidier. Save the raw multiplier for when neither shortcut fits.

### Problem 2 — Find 62.5% of 1600

**Answer: 1000**

**Method 1 (fastest) — Fraction table**
- 62.5% = 5/8. 1600 / 8 = 200, then 200 x 5 = **1000**
- ~6 seconds. This is the whole reason to memorise 1/8 = 12.5%.

**Method 2 — Building blocks**
- 50% of 1600 = 800; 12.5% = 1/8 = 200; 800 + 200 = **1000**
- ~10 seconds.

**Method 3 — Direct multiplier**
- 1600 x 0.625 = 1000. **1000**
- ~15 seconds.

**Use when...** you recognise the "ugly decimal" percentages (12.5, 37.5, 62.5,
87.5, 16.66, 33.33, 66.66) — these are ALWAYS eighths/thirds. Convert to a
fraction instantly; never multiply the decimal.

Fraction table worth memorising: 1/8 = 12.5%, 1/6 = 16.66%, 1/3 = 33.33%,
3/8 = 37.5%, 5/8 = 62.5%, 2/3 = 66.66%, 7/8 = 87.5%.

### Problem 3 — A number is increased by 20%, then the result is decreased by 25%. What is the net percentage change?

**Answer: 10% decrease**

**Method 1 (fastest) — Multiplier chain**
- 1.20 x 0.75 = 0.90 -> 0.90 means 90% of original -> **10% decrease**
- ~6 seconds. No formula, no assumed number.

**Method 2 — Successive-change formula**
- a + b + (ab/100) with a = +20, b = -25
- = 20 - 25 + (20 x -25)/100 = -5 - 5 = **-10%**
- ~12 seconds.

**Method 3 — Assume 100**
- 100 -> +20% -> 120 -> -25% of 120 = -30 -> 90 -> change from 100 = **-10%**
- ~15 seconds, but bullet-proof and never misremembers a sign.

**Use when...** you are confident with decimals, use the multiplier chain — it
scales to three or four successive changes with no extra effort. Use "assume
100" whenever the sign of the answer feels risky; it cannot go wrong.

### Problem 4 — Cost price is Rs 400, sold at 15% profit. Find the selling price.

**Answer: Rs 460**

**Method 1 (fastest) — Profit multiplier**
- 400 x 1.15 = **460**
- ~5 seconds.

**Method 2 — Building blocks**
- 15% of 400 = 60; SP = 400 + 60 = **460**
- ~8 seconds.

**Use when...** for a single clean %, the multiplier (1 + r) is fastest. Switch
to building-blocks when the profit % is awkward but the base is round, or when
you also need the profit *amount* separately.

### Problem 5 — Simple interest on Rs 12,000 at 8% p.a. for 3 years.

**Answer: Rs 2,880**

**Method 1 (fastest) — Per-year interest x years**
- 8% of 12,000 = 960 (one year); x 3 = **2,880**
- ~8 seconds. SI is linear, so "one year then multiply" is always valid.

**Method 2 — PRT/100 formula**
- (12,000 x 8 x 3) / 100 = 2,88,000 / 100 = **2,880**
- ~12 seconds.

**Use when...** always try per-year first for SI — it turns a three-number
multiply into a one-number percentage. Keep the formula for when the rate or
time is fractional and the per-year value is not clean.

### Problem 6 — The average of 5 numbers is 46. One number, 30, is removed. Find the new average of the remaining 4.

**Answer: 50**

**Method 1 (fastest) — Deviation shortcut**
- Removed number 30 is 16 *below* the old average (46 - 30 = 16).
- That surplus of 16 is now shared among the 4 remaining -> +16/4 = +4 each.
- New average = 46 + 4 = **50**
- ~10 seconds, no large sums.

**Method 2 — Total method**
- Old total = 5 x 46 = 230; remove 30 -> 200; new average = 200/4 = **50**
- ~15 seconds. Reliable, always works.

**Use when...** removing/adding one value near the mean, deviation thinking is
faster and reveals *why* the average moved. Fall back to totals when several
numbers change at once, or when the deviation is not a clean multiple.

### Problem 7 — Divide Rs 720 in the ratio 5 : 4.

**Answer: Rs 400 and Rs 320**

**Method 1 (fastest) — One-part value**
- Parts total 5 + 4 = 9; one part = 720/9 = 80.
- Shares = 5 x 80 = 400 and 4 x 80 = 320. **400, 320**
- ~10 seconds.

**Method 2 — Fraction of total**
- 5/9 x 720 = 400; 4/9 x 720 = 320. **400, 320**
- ~12 seconds.

**Use when...** the total divides cleanly by the sum of ratio terms, the
one-part method is quickest and extends to any number of shares. The fraction
route is handy when you need only one of the shares.

### Problem 8 — A father is 3 times as old as his son. In 12 years, the father will be twice as old as the son. Find their present ages.

**Answer: Son 12, Father 36**

**Method 1 (fastest) — Back-solving / plug the answer**
- Try son = 12 -> father = 36. In 12 yrs: 24 and 48. Is 48 = 2 x 24? Yes. **Done.**
- ~10 seconds if the numbers are small; test the "roundest" option first.

**Method 2 — Algebra**
- Son = x, father = 3x. Then 3x + 12 = 2(x + 12)
- 3x + 12 = 2x + 24 -> x = 12; father = 36. **Son 12, Father 36**
- ~25 seconds. Always works, even for ugly numbers.

**Use when...** in Prelims MCQs, back-solving from the options beats setting up
equations whenever the answer choices are small integers. Reserve full algebra
for when options are spread wide or fractional.

### Problem 9 — Find the next term: 3, 6, 12, 24, 48, ?

**Answer: 96**

**Method 1 (fastest) — Ratio spotting**
- Each term x 2 (6/3 = 2, 12/6 = 2...). Next = 48 x 2 = **96**
- ~4 seconds.

**Method 2 — Differences**
- Gaps: 3, 6, 12, 24 — themselves doubling; next gap = 48; 48 + 48 = **96**
- ~10 seconds. Confirms the pattern if the ratio looked coincidental.

**Use when...** if consecutive terms have a constant *ratio*, ratio-spotting is
instant. Only drop to differences when the ratio is not constant and you need
to see how the gaps evolve.

### Problem 10 — Find the next term: 5, 11, 23, 47, 95, ?

**Answer: 191**

**Method 1 (fastest) — "x2 + 1" rule**
- 5x2+1 = 11; 11x2+1 = 23; 23x2+1 = 47; 47x2+1 = 95; so 95x2+1 = **191**
- ~10 seconds. When ratios are "almost 2" and terms are odd, test x2+1 / x2-1.

**Method 2 — Differences (doubling)**
- Gaps: 6, 12, 24, 48 — doubling; next gap = 96; 95 + 96 = **191**
- ~12 seconds.

**Use when...** terms roughly double but not exactly, suspect a "x2 +/- k"
operator rule and test it first. If that stalls, the doubling-difference view
usually cracks the same series.

### Problem 11 — Find the next term: 2, 5, 10, 17, 26, ?

**Answer: 37**

**Method 1 (fastest) — First differences (odd numbers)**
- Gaps: 3, 5, 7, 9 — consecutive odds; next gap = 11; 26 + 11 = **37**
- ~8 seconds.

**Method 2 — nth-term formula (n squared + 1)**
- 2 = 1+1, 5 = 4+1, 10 = 9+1, 17 = 16+1, 26 = 25+1 -> next = 36 + 1 = **37**
- ~12 seconds, and it lets you jump to any term directly.

**Use when...** differences form a simple pattern (odds/evens/AP), the
difference method is fastest. Reach for the n^2 +/- k formula when they ask for
a *far* term or the differences themselves are perfect squares apart.

### Problem 12 — Find the next term: 7, 9, 13, 21, 37, ?

**Answer: 69**

**Method 1 (fastest) — Differences are powers of 2**
- Gaps: 2, 4, 8, 16 — powers of 2; next gap = 32; 37 + 32 = **69**
- ~8 seconds.

**Method 2 — Operator rule (term + 2^n)**
- +2^1, +2^2, +2^3, +2^4, then +2^5 = 32 -> 37 + 32 = **69**
- ~12 seconds — same idea, stated as a rule you can verbalise.

**Use when...** the gaps are 2, 4, 8, 16..., you have a powers-of-two series;
read the next gap straight off. This is one of the most common Prelims series
shapes, so train the reflex.

### Problem 13 — Solve: x^2 - 7x + 12 = 0

**Answer: x = 3 or x = 4**

**Method 1 (fastest) — Sign-pattern + sum/product**
- c is +, b is - -> both roots positive.
- Need product 12, sum 7 -> 3 and 4. **x = 3, 4**
- ~8 seconds. This is pure mental splitting, no writing.

**Method 2 — Factoring on paper**
- x^2 - 7x + 12 = (x - 3)(x - 4) = 0 -> x = 3, 4. **x = 3, 4**
- ~15 seconds. Same work, just written out.

**Use when...** for quadratic-comparison questions (the x vs y type), always use
the sign pattern first: signs of the roots come *free* from the signs of b and
c, before you even find the values. Sign rules: (+b, +c) -> both roots negative;
(-b, +c) -> both positive; (c negative) -> one of each sign.

### Problem 14 — Two equations. Find the relation between x and y.
**I. x^2 - 5x + 6 = 0    II. y^2 - 7y + 12 = 0**

**Answer: x <= y**

**Method 1 (fastest) — Sign pattern, then compare ranges**
- Both equations: (-b, +c) -> all roots positive.
- x: sum 5, product 6 -> x = 2 or 3. y: sum 7, product 12 -> y = 3 or 4.
- x is in {2, 3}, y is in {3, 4}. Every x <= every y (2<3, 2<4, 3=3, 3<4).
- Relation: **x <= y**
- ~20 seconds.

**Method 2 — Factor both, tabulate the four comparisons**
- (x-2)(x-3)=0 and (y-3)(y-4)=0. Compare each x with each y: all give x <= y.
- **x <= y**
- ~30 seconds — thorough, catches the "equal at 3" case that makes it <= not <.

**Use when...** in these compare-the-roots questions the trap is x < y vs
x <= y. Always list both root sets and check whether the ranges *touch* (here
both contain 3), which forces the "or equal to" sign.

### Problem 15 — A finishes a job in 12 days, B in 18 days. How long together?

**Answer: 7.2 days (7 days 4.8 hours)**

**Method 1 (fastest) — LCM units**
- Total work = LCM(12, 18) = 36 units. A = 36/12 = 3 units/day, B = 36/18 = 2.
- Together 5 units/day -> 36 / 5 = **7.2 days**
- ~15 seconds, and no fractions until the last step.

**Method 2 — Product / sum formula**
- xy/(x+y) = (12 x 18)/(12 + 18) = 216/30 = **7.2 days**
- ~15 seconds. Neat for exactly two workers.

**Use when...** the LCM method scales to three or more workers, wages, and
pipes-with-leaks — make it your default. The xy/(x+y) formula is a fine
one-liner but only for the two-worker case.

### Problem 16 — A car covers 240 km at 60 km/h. Find the time taken.

**Answer: 4 hours**

**Method 1 (fastest) — Direct division**
- Time = distance / speed = 240 / 60 = **4 hours**
- ~4 seconds.

**Method 2 — Unitary**
- 60 km takes 1 hr -> 240 km = 240/60 = **4 hours**
- ~8 seconds — the reasoning version, useful if the numbers are not clean.

**Use when...** basic D = S x T, just divide. The unitary phrasing only earns
its keep when one quantity is fractional and you want to reason in steps.

### Problem 17 — Two trains, 36 km/h and 54 km/h, move in opposite directions. Combined length 250 m. Time to cross each other?

**Answer: 10 seconds**

**Method 1 (fastest) — Relative speed, convert once**
- Opposite directions -> add speeds: 36 + 54 = 90 km/h.
- 90 x 5/18 = 25 m/s. Time = 250 / 25 = **10 s**
- ~15 seconds. Add first, convert once, divide once.

**Method 2 — Convert each, then add**
- 36 x 5/18 = 10 m/s; 54 x 5/18 = 15 m/s; relative = 25 m/s; 250/25 = **10 s**
- ~20 seconds. More steps, same result.

**Use when...** combine the speeds *before* converting km/h to m/s — one
conversion instead of two. Remember: opposite directions add, same direction
subtract; the crossing distance is the *sum* of the two lengths.

### Problem 18 — A boat's speed in still water is 10 km/h, stream is 2 km/h. It goes 24 km downstream and returns. Total time?

**Answer: 5 hours**

**Method 1 (fastest) — Two clean divisions**
- Downstream 10 + 2 = 12 km/h -> 24/12 = 2 h.
- Upstream 10 - 2 = 8 km/h -> 24/8 = 3 h. Total = **5 h**
- ~15 seconds.

**Method 2 — Combined round-trip formula**
- t = d/(b+s) + d/(b-s) = 24/12 + 24/8 = 2 + 3 = **5 h**
- ~15 seconds — same arithmetic, stated as one formula.

**Use when...** compute down- and up-speeds separately; the two divisions are
usually cleaner than plugging a combined formula. The formula matters more when
they give total time and ask for stream speed (then set it up and solve).

### Problem 19 — DI. A company has 1,200 employees split across four departments: A 25%, B 30%, C 20%, D 25%. How many are in departments B and C together?

**Answer: 600**

**Method 1 (fastest) — Build a 1% base once**
- 1% of 1,200 = 12. Then any department is (its %) x 12.
- B = 30 x 12 = 360; C = 20 x 12 = 240; B + C = **600**
- ~12 seconds. And now every other question on this data set is one multiply.

**Method 2 — Per-question multiplier**
- B = 1200 x 0.30 = 360; C = 1200 x 0.20 = 240; sum = **600**
- ~15 seconds for this one part, but you re-multiply for each new sub-question.

**Use when...** a DI set has one fixed total feeding many questions, spend 5
seconds building the "1% value" (or "per-unit value") once — then the whole set
collapses to small multiplications. Per-question multiplying is fine only if you
will answer a single part and move on.

Shortcut check here: B + C = 30% + 20% = 50% of 1200 = 600 directly. Combining
the percentages *before* multiplying is often the true fastest route — spot it
whenever the question asks for a sum or difference of categories.

### Problem 20 — In what ratio should rice at Rs 30/kg be mixed with rice at Rs 40/kg to get a mixture worth Rs 34/kg?

**Answer: 3 : 2 (cheaper : dearer)**

**Method 1 (fastest) — Alligation cross**
- Cheaper 30, dearer 40, mean 34.
- Cheaper part = (40 - 34) = 6; dearer part = (34 - 30) = 4.
- Ratio = 6 : 4 = **3 : 2**
- ~10 seconds. Distance from the mean, cross-swapped.

**Method 2 — Algebra**
- Let cheaper : dearer = k : 1. (30k + 40)/(k + 1) = 34
- 30k + 40 = 34k + 34 -> 4k = 6 -> k = 1.5 = 3/2 -> **3 : 2**
- ~30 seconds. Slower, but shows the machinery behind alligation.

**Check:** (3 x 30 + 2 x 40)/5 = (90 + 80)/5 = 170/5 = 34. Correct.

**Use when...** any "mixture to hit a target average" question — price, percentage
purity, average marks, average age of two groups — solve by alligation: it is
the same cross every time. Keep the algebra only for verifying or for when the
mean itself is the unknown.
